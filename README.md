# 语言学工具书 · 两个站点 + 书库

纯静态站点，双击即可本地查看，也可以部署到 Netlify / GitHub Pages。

---

## 目录结构

```
术语查询/     index.html + data.js   19,350 条术语（词典 3 + 流派史 2 + 语法专著 8）
教材对比/     index.html + data.js   17 本书全文 + 488 组概念对比（6 本现代汉语教材）
书库/         22 本研读底本（md + meta.json），按五类分目录
书籍md/       15 个原书 OCR 合并 md（原书全文）
netlify.toml  部署配置：publish = "."
对比表构建说明.md   对比表怎么选词、怎么改
上传清单.md         哪些文件必需、哪些可选
```

---

## 部署

**Netlify**：把本目录内容推到仓库 → 构建命令留空 → 发布目录填 `.`
**本地查看**：双击 `术语查询/index.html`（`data.js` 必须同目录）

网址形如 `你的域名/术语查询/`、`你的域名/教材对比/`。

## 术语查询站

- **19,350 条**：词典正文 14,480 + 汉英对照 3,474 + 旧版补录 1,411（去重后）
- 来源：牛津语言学词典、现代语言学词典、语言学与应用语言学百科全书，外加语言学流派史与汉语语法专著
- 搜索按词目优先排序；可按来源筛选（牛津 / 现代 / 百科 / 汉英对照）
- 词条详情：全文、复制引用、编辑、导出 JSON
- 理论页 28 个（5 个六块精修 + 23 个章级整理）、人物卡片 358 张
- 快捷键 `/` 聚焦搜索、`Esc` 清空；长释义自动折叠
- 每条标页码状态：「已核对 / 推定 / 旧版估算」

## 教材对比站

**阅读**

- 17 本书全文，保留原书标题层级与表格
- 左侧目录（章 › 节）点击跳转，随阅读高亮当前位置
- 页码标记（第 N 页）、字号三档、限宽排版、进度条、回到顶部、面包屑

**概念对比（488 组）**

- 自动抽取北大、胡裕树、齐沪扬、邵敬敏上下、张斌 6 本教材
- 领域树（语音/文字/词汇/语法/修辞/概论 › 学科二级）+ 拼音字母索引
- 卡片直接列出提到该概念的教材名；点开看各书原文（该段 + 前后各一段）
- 别名合并（词组/短语、声调/字调、外来词/借词…），依据是书里「也叫/又称」原话
- 双栏对照、一键导出 Markdown、出现位置索引（点页码跳原文）

**看板**：概念总数、6/5/4/3/2 本覆盖分布、各教材贡献数、领域分布、共识榜、分歧榜

**候选清单**：列出高频但未进表的概念，可勾选导出，用于后续补充

**全文检索**：两个字以上即可查，命中段落可跳转到原文

## 内容核对

正文对原书 md 覆盖率 **99%**（按汉字串比对），缺口集中在序言、出版说明、内容简介等前辅文。

已清理：LaTeX 公式残渣、`\underset` 着重号、替换字符、HTML 标签、扫描水印（Anna's Archive / ISBN / 定价 / CIP 版权页）。正文里的引用网址（Ethnologue 等）保留。

## 离线与分享

- 零外部依赖，不需要联网或构建工具
- 分享给别人：整个文件夹压缩发送，或用项目根目录 `离线单文件/` 里的单文件版
- 文件夹形式必须保持 `index.html` 与 `data.js` 同目录，否则白屏
