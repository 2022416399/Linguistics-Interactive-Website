## 特性

- **单文件页面**：每章独立 HTML，无外部依赖，离线可读
- **手写 SVG 图解**：层次树、变换矩阵、配价框架等全部矢量重绘，浅色底恒亮，不随暗色主题变暗
- **出处角标**：关键说法标注底本行号（`data-cite`），点击弹出原文与出处，含事实账本
- **先猜后看**：核心论点设 `data-guess` 互动，先思考再揭晓
- **自测题**：每章附选择/判断题，双反馈（对/错均给解释）
- **阅读五件套**：字号与阅读进度记忆（localStorage）、`prefers-reduced-motion` 动效降级、`prefers-color-scheme` 暗色适配、pushState/popstate 返回键、移动端 viewport

## 本地预览

任选其一：

```bash
# 方式一：直接用浏览器打开
open index.html            # macOS
start index.html           # Windows

# 方式二：起一个本地服务（推荐，避免个别浏览器的 file:// 限制）
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 部署（Netlify）

纯静态站点，无构建步骤。仓库根目录即发布目录，入口为 `index.html`：

1. 推送本目录到 GitHub 仓库
2. Netlify → Add new site → Import from Git，选择该仓库
3. Build command 留空，Publish directory 填 `.`（或仓库根）
4. Deploy

仓库已带 `netlify.toml`，上述参数会自动应用。
