象似性入门：符号不只靠约定

索绪尔说形式与意义的关系"事实上是任意的"；Peirce 提醒我们还有指示和图象两类带着自然基础的符号。象似性，就是语言在模仿我们心中的世界模型。

动手分一分：这些例子分别属于哪种象似性？先点例子，再选类别

先点例子，再选类别：本章的句法原则有三类，外加拟声。

先猜再看：英语 bow-wow（汪汪）和德语 waw-waw 开首唇音不同。按索绪尔的理论，这类声音象征该怎么定位？

答案是 b。索绪尔主张大多数词的形式只是通过规约与内容相联系，形式与意义"事实上是任意的"；bow-wow 这类声音象征在他的理论里充其量只看作例外。

Peirce 则把这类模仿归入"图象"：表达与对象有相似性的符号——认知语言学要做的，是把相似性挪到"概念化"层面上来理解。

Peirce 的三类符号与两种"图象"

只有"象征"（symbol）是约定俗成的，接近索绪尔的任意符号；"指示"（index）具有指明功能，由人称代词、指示代词和 here/there/now/then 这类直指副词实现，天气风向标指明风向、烟是火的信号也属此类。"图象"（icon）与对象有相似性：模仿式的叫"映象"（image，如 bow-wow），结构相似式的叫"拟象"（diagram，如语言成分排列像事件结构）。

句法领域由此提出三条象似原则：象似顺序（小句跟着事件的自然时间顺序）、象似邻近（关系近的成分靠近放）、象似量（表达式长度对应信息量）。

分类游戏的答案没有唯一标准表述，但每一条都能在原文找到依据——点开角标核对。

句法象似：排队与黏着都有道理

关系近的成分必须靠近放在一起——形容词排队如此，动词词干与体、时、情态标记的黏着距离也如此。

实验台 A：把修饰语排成可接受的英语短语（名词 pizza 固定在最后）

当前短语：____ ____ ____ ____ pizza

只有 the famous delicious Italian pepperoni pizza 可接受。pepperoni 是比萨饼的固有组成成分，必须紧贴名词；Italian 表示产地，第二接近；delicious（特点）与 famous（评价）离名词较远。

认知解释：语言是一维线性序列，而现实中所有特色融合在同一个物体上——邻近性模仿的是范畴间的心理邻近。

实验台 B：按"离动词词干由近到远"依次点出三种标记

正确顺序：体标记 → 时标记 → 情态标记。She was working 里 -ing 紧贴词干；不表体时 -ed 可直接附着；而 ★She swim-could 不合法——情态标记不能移近词干。

概念理由：DURATION（持续）、PROGRESSION（进行）与 WORK 范畴关系最密切；TEMPORAL LOCATION（时间位置）远一些；ABILITY（能力）与 SWIM 的关系最远。

名词一侧同理：复数标记直接附着名词词干，格标记通常第二近；children's 里不规则复数 -ren 比属格 -s 更近，且顺序不可颠倒。

量象似性：长的一定更重要吗

Givón 的规则：语言材料的量与被处理信息的重要性和可预测性程度相对应。同一个遇见"她"的场面，代词 her → the girl from next door → this fair-haired, fragile, just unbelievably beautiful creature，表达式一路变长，信息的重要性和意外性也一路升高。

这也解释了人称代词为什么通常比完整名词短语短、标准形式为什么往往比对比形式短——法语非重读的 je（我知道、我喜欢）与对比形式 moi 就是一对。

句法象似的三条原则，都能改写成"语言层面 ↔ 概念化层面"的对应关系。

拟声词与文化概念化

拟声词模仿的不是世界本身，而是我们依赖文化的概念化：狗叫在英语里是 bow-wow，在法语里是 ouaf ouaf；/i/ 让人想到小、亮、愉快，/u/、/o/ 则想到大、强、不快。

翻一翻：先点动物，再点语言，看拟声词怎么变

同一头牛，六种语言六种叫法。

先猜再看：Tolkien 给《指环王》人物取名。Aegnor、Carcharoth、Earendil、Morgoth 这四个名字里，哪几个是正面人物？

答案是 a。不熟悉 Tolkien 的被试大多能凭语感把名字分对：前元音（/i/、/e/）归正面人物，后元音（/u/、/o/）归反面人物——Aegnor、Earendil 属前者，Carcharoth、Morgoth 属后者。

Tolkien 自编的三种人工语言也呈同样分布：两种"正面"精灵语前元音比例高，"反面"兽人语 /u/ 占四成、辅音对元音比达 1.7。

实验证据与一个反转

Sapir 1929 年起，[mil] 与 [mal] 这类无意义话段的大小指派在实验中反复得到证实；/sw/ 开头的 swing、sway、sweep、swirl、swagger 则让人产生"摆动"的印象。

反转在于日常词汇自己拆台：英语 small/big、good/bad 的语音形式恰好与大小、好坏的联想相反；Masuda 的解释是小/大对立源于发 /i/ 与 /u/ 时口腔共鸣腔的小与大——而我们的概念化容得下相互竞争的表达式（bow-wow 与 dog 本来就能切换使用）。

声音象征不是"语言像世界"，而是"语言像我们对世界的概念化"——文化模型不同，叫声的写法就不同。

词汇演变：围着原型稳中求变

语言似乎有一种内在的稳定性，同时又灵活到容得下实质的词汇演变——原型范畴同时解释了这两点。

拖动时间轴：看 coach 的原型几百年里怎么搬家（1500–2000）

先猜再看：古英语里，fugol 和 bryd 分别指什么？

答案是 b。古英语 fugol 指所有种类的鸟；bryd 已用于 YOUNG BIRD（幼鸟）范畴。后来 fugol 转指家禽（现代 fowl），bryd 泛化接手整个 BIRD 范畴——因为幼鸟范畴原本就包含 BIRD 的全部主要属性，范畴中心未变，转换才得以顺利完成。

"小"这个幼鸟的重要属性，成了 bird 从幼鸟范畴走向全范畴的拐杖。

原型转移与原型分裂

COACH 的换代中，"用于客运"这个功能属性把成员拢在一起：动力来源从"马拉"到"机车拖行"再到"自动推进"变化巨大，但"大而封闭的车厢、四个轮子、里面有座位"整体转移到了新原型身上，所以使用者几乎无感。

例外是铁路客车：它不能在公路上独立使用，于是 coach 在这里分裂出了另一个原型——这样的原型分裂在具体物体范畴不常见，在抽象范畴常见得多。IDEA 自 15 世纪进入英语后，就从全局原型分裂出 CONCEPT（the idea of）、BELIEF（the idea that）、AIM（the idea is to）、SUDDEN INSPIRATION（have/get an idea）四个局部原型。

传统分类只有泛化、特化、比喻、替代四种过程；原型视角追问的是：变的是哪一部分，什么没有变。

语法化斜坡：从 go 到 gonna

实义动词 go 一路下滑成助动词 gonna：转喻打前站，隐喻接力，最后只剩音变——语法化就是词汇单位慢慢承担语法功能的过程。

点阶段按钮，看例子和背后的认知机制

为什么是 go，传统描写差在哪儿

位移事件三要素——目标取向、变化、视点——在 going-to 的语法化里轮流登场；只有 go 这样强调结尾路径视窗的动词才具有目标取向，才容得下带意图潜势的不定式，leave（起点视窗）、pass（中间视窗）、stagger/ride/fly（方式）都不行。

传统语法把第二阶段叫"重新分析"、第三阶段叫"类推"；认知解释换成转喻与隐喻，好处是能说明限制：You are going to be friends 可以说，The earth is going to be round for ever 不可接受——going-to 的预言用法只留给不排斥变化的状态。

Heine 的框架把语法化接到命题图式上：方位、位移、动作三个基本图式，派生出的等式、伴随、拥有、方式、状态变化、意愿六个图式——意愿产生英语 will 将来时，状态变化产生德语 werden 将来时，很多非洲语言用伴随发展出进行体。

认知分析支持"词汇→语法"的第一阶段单向演化；反向的"去语法化"若真出现，也应有工具去处理。

先猜再看：West 编《英语最常用词汇表》时，除了频率还想找的是什么词？

答案是 b。West 知道频率本身不充分，补了覆盖率、对定义和构词的价值、风格中性化、可用度、学习难易度等标准——这份清单读起来就像基本层次范畴的描写；结论是"基本层次范畴似乎提供了通向常用词汇的最佳通道"。

语料库频率表恰恰由 the、of、and 这类功能词领头——单靠频率选词会失真，这正是 West 加标准的原因。

课堂细节：原型例子、词汇场与介词网络

词义用典型例子（知更鸟）而非奇异例子说明更易掌握；英语 bread、法语 pain、德语 Brot 原型不同，正是跨文化认识的好机会。词汇场之所以好用，是因为它反映心理词库的构建方式——且要打破词类界限；有经验的教材编写者进入类关系之前先穷尽部分-整体关系，连 ANIMAL、CLOTHES、FURNITURE、SPORTS 这些分类模型（图 7.12 中带星号）也有资格充当部分-整体模型的候选。

专门用途英语要换基本层次：给植物学家不该停在 tree、flower，要用更精细的术语。给习语指出底层隐喻（+FIRE+ 隐喻统辖愤怒、爱、想象、冲突、热情）能帮助习得；介词 over 的 A-B-C 轨迹可以用翻页书或猫跳墙动画来教，完结义靠突显最后阶段 C 自然呈现。

还有些句子被整体当成"块"在前语法模式里处理（kick the bucket、white elephant）——完形感知是语言输入非分析处理的条件，小学课堂的角色扮演、顺口溜、谜语、童话正该按这个标准来选。

名词语法与动词形式也有完形化的余地：与其记可数/不可数二分，不如按人、物概念分类（单个物体、物质、"成对"物体、事物集合）；时体标记则有原型可依——yesterday/ago 指向过去时，always/often 支撑简单式，at this moment 支撑进行体，标记充当用法的参照点。

三件套：目标要交际（最终跨文化），方法行为取向、以学习者为中心，途径走认知-经验。

文本策略：象似性放大到整篇

旅游指南像导游带路（路径策略），电话号码簿和新闻报道则靠分类-加权策略——读者把这些行为结构从自身体验整体转移到文本理解上。

排一排：一次导游参观按什么顺序展开？依原文顺序点选步骤

六步来自原著的路径策略成分清单，顺序点错会提示。

原著的清单是：以邀请同行达到高潮的揭幕仪式 → 沿路径行走 → 在不同路线中作出选择 → 指出有趣的事物 → 对它们进行解释 → 恰当的结束仪式。

旅游手册的写法印证了它："跨过 Llancaiach Fawr 的门槛，回到 350 多年前的大动乱和内战时期……"—— step over、enter、guide 这些路径动词与迎候、服饰、讲解细节结合在一起。

路径策略不止用于旅游指南

路径概念是基本意象图式之一，也是主体/背景对立、射体、位移事件图式的支柱。路径策略为说明书、程序文本（菜谱、自己动手的手册）、按序时记录（纪实、历史小说、传记）充当参考；它的效果甚至超出语言媒介，对景点推介类电视节目同样关键。

电话号码簿和新闻报道没有"引导"性质，却也靠象似支持：分类策略（汇集材料、分析大小/形状/颜色/价值等参数、定分类原则、分阶段、决定显示方式）常与加权策略结合；新闻报道"自上而下、按递减的重要性排列"，正是分类-加权策略的体现，也解释了结尾焦点为什么好用。

象似性的最高境界：不是单个词语模仿声音，而是整篇文本模仿我们的行为经验。

① 动词词干与体、时、情态标记的距离，说明了什么概念关系？

看答案

体标记离词干最近，因为 DURATION（持续）、PROGRESSION（进行）与 WORK 这类动词行为范畴关系最密切；TEMPORAL LOCATION（时间位置）远一些，ABILITY（能力）这类情态概念与词汇范畴的关系最远——所以 ★She swim-could 不合法。名词一侧同理：复数标记最近，格标记第二近。

② coach 的原型从贵宾马车一路换到公共汽车，为什么使用者几乎无感？

看答案

因为"用于客运"这个最重要的功能属性，连同"大而封闭的车厢、四个轮子、里面有座位"整体转移到了新原型身上；变的只是动力来源（马拉→机车拖行→自动推进）。例外是铁路客车——不能在公路独立使用，分裂出了另一个原型。

③ 为什么 You are going to be friends 可以说，The earth is going to be round for ever 不可接受？

看答案

going-to 将来时的预言用法受"变化<>位移"关系限制：只用于表示人的好恶、友谊这类"非永久而易于变化"的状态；"地球将永远是圆的"与变化观念冲突，越过了映射限制。It's going to rain 可以，是因为有当下可见的征兆作参照点。

考前速记（折叠）
  • Peirce 三类符号：象征（约定）、指示（指明：here/there/now/then、风向标、烟）、图象（相似：映象＋拟象）。
  • 句法象似三原则：顺序（小句跟着事件时间顺序）、邻近（关系近的成分靠近）、量（长度对应信息量与重要性）。
  • 认知转向的关键：不跟真实物体比，跟范畴与认知模型比。
  • 形态证据：动词词干—体—时—情态，距离递减；名词词干—复数—格，距离递减；children's 不可换序。
  • 词汇演变的传统四分：泛化、特化、比喻、替代（语义转移）；认知视角加原型转移与原型分裂。
  • BIRD 案例：隐喻多来自边缘属性；fugol（所有鸟）→fowl（家禽），bryd（幼鸟）→bird（全范畴），中心未变。
  • 语法化四阶段（going to）：实义位移 → 转喻扩展 → 隐喻扩展 → 音系缩写；传统叫重新分析与类推。
  • Heine 命题图式：方位、位移、动作三个基本图式，派生等式、伴随、拥有、方式、状态变化、意愿。
  • 教学三件套：目标（交际→跨文化）、方法（行为取向、学习者中心）、途径（原型、基本层次、主体/背景、完形）。
  • 不定式＝情景的个别实例；动名词＝从单一事件剥离出的情景；这种对立要整体培养敏感性。
名词快查（折叠）
  • 象似性：语言层面与概念化层面之间的相似关系，不是语言与现实对象的直接相似。
  • 映象 / 拟象：Peirce 的两种图象——映象是模仿（bow-wow），拟象是结构相似（成分排列像事件结构）。
  • 指示：具有指明功能的符号，常借时空定位实现，如 here/there/now/then。
  • 原型转移：范畴核心属性整体换代，如 coach 从贵宾马车到公共汽车。
  • 原型分裂：一个范畴裂出多个局部原型，IDEA（概念/信念/目的/灵感）最典型。
  • 语法化：自主的词转变为语法成分的角色；词汇单位承担语法功能的过程。
  • 重新分析 / 类推：传统语法给 going-to 第二、三阶段的命名；认知说法是转喻与隐喻。
  • 命题图式：Heine 框架中表征过程和事件的结构，语法范畴从最一般的图式发展而来。
  • 认知-经验途径：经由原型、基本层次、主体/背景、完形习得外语的通道。
  • 词汇场：反映心理词库构建方式的语义相关词项聚集，须打破词类界限。
  • 路径策略 / 分类-加权策略：两类有象似支持的文本策略，分别对应"导游带路"与"按参数排序"。
