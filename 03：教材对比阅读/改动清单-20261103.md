## 二、表格：恢复原书的行结构

源数据里，三线表和词表**本来就保留着换行**（一行一个词条/一行一个表行），是渲染时被 `join(' ')` 拼成了一整段。现在改为按行渲染：

- 多行段落用 `<br>` 分行，不再挤成一段；
- 这类段落取消首行缩进、行距略收紧，读起来就是表格/清单的样子；
- 概念对比页的摘录同步处理。

效果示例（北大本第 57 页）：

```
开发 kāifā 开花 kāihuā
开方 kāifāng 开荒 kāihuāng
分期 fēnqī 婚期 hūnqī
废话 fèihuà 会话 huìhuà
```

涉及 119 个多行段落（词表、声韵母表、正反问句表等）。源数据本身已被 OCR 压成一行的表格（如半元音表）无法恢复列，只能保持原样。

### 示例行：连着的一起紧排

单独占一行的例句如果各自成段，段间距会把它们拆得很散。现在连续两行以上的例句会合并成一个「示例块」：

- 块内逐行紧排（行距 1.9，段间距 0），整块左缩进 2em，和正文首行缩进对齐；
- 以“：”结尾的引导句与示例之间收紧到 0.25em，读起来是「例如：」紧接例子；
- 单行示例仍按普通段落排，避免把对话、签名等短段也并进来。

判定规则（覆盖各书的不同例句形态）：

| 形态 | 例子 | 判定 |
|---|---|---|
| 编号例句 | `① 我说的就是他呀（tā ya）!`、`（1）他来了。` | 开头是（1）或① 即算 |
| 特征矩阵 | `母亲[+直系, -男性, …]` | 含 `[ ] + =` 即算 |
| 记音/英文 | `(1) So long as men can breathe…` | 英文行放宽到 90 字 |
| 译文/括注 | `（只要一天有人类，或人有眼睛，` | 以（( 开头即算 |
| 普通短句 | `二十 ＝2×10`、`我早就报了名了` | ≤46 字、无句末标点 |
| 散文 | `“十”和“多少”只能做位数词…的系数。` | 有句号或逗号 → 不算 |

全站共 **5743 个示例块、22870 行**，17 本书全部生效。

### 标点层面的校对

- **半角括号夹中文 → 全角**：约 7,500 处（首轮 7,338、嵌套补转 84、配对解析补转 78）。中文正文里“（包括ao、iao）”“（第一版，1996）”这类括注统一成全角；只有拼音/英文的括注（如 `(tā ya)`）不动。剩余约 14 处是括号本身就不配对的 OCR 残片，保留原样。
- **顿号被吞**：朱德熙《现代汉语语法研究》“I，， 都是不同的结构” → “I、II、III 都是不同的结构”。
- 另扫了重复句号、标点前空格、方框乱码等，未发现其他问题；“??”是“较不合格”的语言学记号，保留。
- **半全角混用的重复括号**：12 处（如 `连动词组充当谓语的句子(（例(3))`），统一收成全角单括号。
- **“？。”连用**：3 处（Fromkin、张敏），删去多余句号。
- **含中文的半角括号**：已全部转为全角，剩余 0 处（用严格正则复核）。
- 其余“不配对”经核查是正常排版，不是错误：
  - **序号式**：“1）2）3）”“（1）……”这类只有右括号的枚举，全书大量使用（如范晓 705 处、张斌 569 处）；
  - **跨页断开**：一句话被页码标记切成两段，左括号在页末、右括号在下一页开头（如“语音节律（包括轻重、停顿、音｜第 60 页｜节多少……等）”），属正常分页；
  - **OCR 丢字**：极少数位置原文字符被吃掉（如北大“否定一方必肯定另（方的反义词”“提供更多（贷，承诺……”），补括号会猜错，保留原样。
- 因此**没有**对“缺右括号”做批量补全——试运行会产生“））”“例如）：”这类错误，已放弃。
- 顺带修好一处被批量替换误伤的 `<sup>` 标记（Fromkin 的 `(^{*}Who did Jack…`）。

> 说明：这是“可核实的错字”，不是逐字校勘。正文里仍可能有 OCR 错误（如“基市”之外的形近字），需要对照原书逐页核，不能靠规则批量替换——实测“实调”“动调”“代调”都是正确词（事实调查、活动调节、现代调类），批量替换会误伤。
