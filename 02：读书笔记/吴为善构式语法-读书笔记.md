# 《构式语法与汉语构式》读书笔记

> **原著**：吴为善《构式语法与汉语构式》
> **整理依据**：本工作区原始拆书笔记（第1—8章）
> **整理日期**：2026年10月24日

## 全书概览

本书以 Goldberg 构式语法为理论框架，系统考察汉语构式的形成机制与解释路径。第1章梳理构式语法的理论渊源及 Goldberg 1995、2006 两个阶段的核心主张；第2章以词语复合的整合等级为切口，讨论概念整合与框架构式；第3章提出"构式原型—扩展承继"的分析模型，处理多义构式的承继网络；第4章从句法同构切入多义解读（数量同构、NV 称谓同构、VR 虚实同构）；第5章聚焦构式赋义与话语功能（主观量、感受性、消极义）；第6章从语用心理与语境适切度解释反预期构式；第7章讨论参数变量与构式变异（"有"字构式分化、2+1 韵律框架复合化）；第8章总结内部承继与外部承继，并归纳语用驱动、语义范畴、句法形式三层理据。

核心主张：构式是形式与意义的配对体；构式义与词汇义通过承继关系互动；汉语构式的个性须放在"原型—扩展"网络中定位，而不能以单一构式框架简单套用。

## 第1章 绪论

### 一、概念引入

构式语法主张句式本身即意义单位，整体大于部分之和。本章述其来路、Goldberg 前后期之别，并以四个汉语构式示范操作。

### 二、核心内容与论点

#### （一）理论渊源

- 格语法（Case Grammar）→ 框架语义学（Frame Semantics）：为构式语义建构提供平台。
- 格式塔语法（Gestalt Grammar，Lakoff）：模板（template）作整体涵盖深浅两层，无转换；"整体而非部分组合"成为思路基础。语义地图（Croft）、意象图式（Langacker）则解释承继与心理依据。
- 对立面是模块式语法观（modular grammar）：语音、句法、语义分层，"词汇+规则"，不含语用；解释不了 kick the bucket，只能视习语为例外，构式语法反以习语为入口（Fillmore 1988）。

#### （二）Goldberg 1995：基础阶段

- 三特征：词库与句法无界（皆形义配对）；语义与语用无界（焦点、话题、语域入构式）；生成性而非转换性（单层次）。
- 定义：当且仅当 C 为〈Fi, Si〉结合体，而 Fi 或 Si 的某方面不能从构件或已有构式精确推导时，C 即构式。
- 基本句子本身即构式，独立于动词；同一动词在不同构式的意义差别归因于构式。

#### （三）Goldberg 2006：发展阶段

- 目标转为"概括的本质"（成人知识与儿童习得、跨语言概括）；全书三部分：回顾定位、习得与能产性限制、功能与信息处理。
- 定义改为：形式或功能某方面不能严格预测即构式；完全可预测而频率足够高者亦可为构式。
- 不可预测性不再是必要条件，定义由"形式与意义"扩至"形式与功能"，据"识解世界的方式""所见即所得"，遂更名认知构式语法（CCG）。

#### （四）汉语构式研究综述

- 前史：王力称把字句为"处置式"，已概括其构式义；朱德熙（1982）分"NP[处所]+V着+NP"为 C₁ 存在静态（墙上贴着标语）、C₂ 活动动态（台上唱着戏），已指多义变体与隐喻承继。
- 规模：90 年代中期后核心期刊 40 余篇，新世纪数百篇。两大重点：基于"同构性"的多义变体；基于"理据性"的承继链接。
- 外围支撑：时间顺序（戴浩一）、有界无界（沈家煊）、可别度领先（陆丙甫）。

#### （五）研究范式的步骤

①精确描写构式与构件属性；②梳理同构多义变体；③（原文未收录，待核对）；④论证话语功能与语境适切度；⑤以认知心理解释承继理据。

#### （六）四个范式示例

**1. 双及物：能产性**

- 旧法按位置定义（马庆株 1983 十余类；李临定 1984 按动词分类），除 VNN 外无共同句法特征，动词无可概括特点，与"三价"互相界定近乎循环。
- 张伯江（1999）改称"双及物构式"（ditransitive construction，整合视点），形式 V+N₁+N₂，义为"有意的给予性转移"，给予义由句式带来。
- 给予方式隐喻：现场给予类（给、借、送、赔）不能变"A 给 R+VP"；允诺指派类（答应、拨、分配）变换受限。

**2. 双谓词：理据性承继**

- 高增霞（2006）：连动式是典型范畴，成员临摹三层先后顺序，典型度不同。
- 客观层（典型）：时间先后，可入"先…后…"，如"下午吃了饭看电影"。
- 逻辑层（非典型）：现象+意义，分"表示"类（鼓掌表示欢迎）、"想/要"类（抓着绳子要往下跳）、肯定否定类，无[先后]。
- 认知层（边缘）：背景+目标，即"V₁着+V₂"，如"大妈端着一盘炒鸡蛋送上桌"。
- 时间先后最基础却最不显著，人惯读为因果、条件、目的，故典型连动式跨语言表广义因果。
**3. 处置义：主观性**

- 沈家煊（2002）分客观处置与主观处置。情感上表现为移情（empathy，Kuno 1987）：施事成责任者、受事成受损者；视角上表现为对受事量的主观判断。根本动因非"受事完全受影响"，而是受事成为移情对象；"都"字管辖受事必作把字宾语，是移情的"语法化"。

**4. 强调义：非典型变异**

- 典型式"连 XP+都/也+VP/AP"，以"连"标预设可能性低端，靠反差强调。
- "连"是话题标记，强制后接述题，故 XP 不能为谓语核心（\*老王连敢吃老鼠肉）。此缺口催生非典型连字句（刘丹青 2005）；构式规约化后成分泛化，非典型成分反使构式更典型。

### 三、方法与分析思路

- 换术语即换立场："双宾语"→"双及物构式"，命名完成由分解到整合的转换。
- 原型定范围、理据释边缘；以时间框架检验连动式典型度。
- 最小对立反证：\*他给老师交了一份作业。
- 五步程式：描写→变体→话语功能→认知理据。

### 四、典型案例与语料

1. "他交给老师一份作业。／\*他给老师交了一份作业。"——给予义由构式承担，非"给"字。
2. "下午吃了饭看电影"——可入"先…后…"，是临摹客观时序的典型连动式。
3. "这是书误了他，可惜他也把书糟蹋了。"（《红楼梦》42 回）——"可惜"指向书，见移情。
4. "老王连敢吃老鼠肉。"（不合法）——"连"后 XP 不能作谓语核心，非典型连字句由此缺口而生。

### 五、术语清单

| 术语 | 释义 |
| --- | --- |
| 构式（construction） | 形式与意义（后期为形式与功能）的配对体，整体属性不能由构件完全推导 |
| 构式义 | 构式整体意义，不能从动词或构件意义简单推导 |
| 能产性（productivity） | 构式接纳新成员、派生新变式的能力 |
| 承继链接（inheritance links） | 构式之间基于理据的联结，分内部与外部承继 |
| 最大理据性原则（principle of maximized motivation） | 构式网络按理据最大化组织，亦为判断同构的依据 |
| 移情（empathy） | 说话人认同于句中某一参与者（Kuno 1987） |

### 七、总结复盘

**本章要点**

1. 构式语法是一族共享"形义配对"理念的模型，本书取 Goldberg 一支。
2. 前后期之别在定义：1995 以不可预测性为必要条件，2006 改为频率足够即可，重心由语义转向功能。
3. 汉语研究两条主线：同构多义变体与理据性承继链接；四例则分别示范能产性、理据性、主观性、非典型变异。

**易错点／难点**

1. 把"构式义不可推导"误读为"与构件无关"——构式义仍受构件语义特征约束。
2. 混淆"构式"与"句式"：构式含语素、词、习语、短语各层级。
3. 把连字句的强调义归于"连"字本身，忽略其话题标记属性与强制后接述题的要求。
4. 王力提出"处置式"的年代原笔记作 1943、1945 两说，引用前须核对；全章页码均标"待核对"。

## 第2章 概念整合与框架构式

### 一、概念引入

概念整合（conceptual blending）指从两个认知域择取部分意义，合成一个复合概念结构，主张"整体大于部分之和"：意义靠整合而非相加浮现。本章用它分析双音复合词与四字格框架构式，并以句法表现给"整合度"分级。

### 二、核心内容与论点

#### 2.0 理论前提

- **两要素**：框架（构式、角色指派、2+2 韵律）与元素（入场成分）；框架作用于元素，产出浮现意义（emergent meaning）。
- **构式与整合同一**：一重结果，一重过程；故构式应含复合词、黏合短语乃至常规句式，不止习语。
- **整合分层**：本义整合低，引申义整合高（张云秋、王馥芳 2003），但须有句法佐证。

#### 2.1 第一节 词语复合模式及其整合等级

**一、述宾两字组 V+N。** 选题因述宾与偏正纠缠、部分成员是可扩展的离合词。

- **试剂是"的"**：作者沿"的"功能同一性一线——朱德熙（1961）三分并定为名词化标记，袁毓林（1995）以谓词隐含统一，郭锐（2000）视为饰词标记，陆丙甫（2003）定为描写性标记。取样自高频千词的 25 个动词，得近 400 例。
- **A 级**：皆自由语素、本义整合、表及物动作。可插"的"作受事提取（开车→（他）开的车），可有界化（状语、体标记、补语、数量修饰、"把"字句）；但受双音框架制约，可组配性差、易凝固。
- **B 级**：已成词，N 义不变而 V 义隐喻抽象（洗菜/洗牌/洗钱，讲价/杀价/提价）。半变半不变，故整合不高；不可有界化，仍可插"的"、带动量时量补语（说过三趟媒）。历时（说媒）与共时（买单）整合只差时间先后。
- **C 级**：融为单一概念，浮现义"避实就虚"，三途为整体隐喻（吃醋）、整体转喻（挂拍）、抽象融合（写生）。不能插"的"，但"的"可后附转指主体；功能由行为漂向状态（很吃惊）。
- **D 级**：功能转为指称，词典标名词。机制是事件框架内转喻，转指产物（画像）或用具（提篮）。

**二、黏合定中 N双+N双。** 承朱德熙（1982）黏合/组合之分，视作 2+2 韵律整合，内部不同质。四条标准：能否插"的"、能否替换、能否受数量指量修饰、能否作主宾指称。

- **A 级**：皆本义、具称谓性，四条全通（木头地板）。
- **B 级**：a 类 N₁ 对 N₂ 核心义素作下位分类，近于区别词，不宜插"的"（桥梁专家、细菌武器）；b 类以隐喻义入场（窗口行业、金融风暴），亦无插"的"基础。
- **C 级**：转喻生浮现义（圆桌会议＝平等、苏州园林＝风格、皮包公司＝投机）。插"的"即转领属类，非平行结构；替换失义，属非等价替换（绅士风度是例外）。
- **D 级**：整体隐喻，字面义脱钩，凸显描写性（狐狸尾巴、表面文章）；"表面文章"不受数量修饰，因"文章"失原型性。
- **矩阵**：A 四项全 +，B 首项 −，C 前两项 −，D 仅末项 +。

#### 2.2 第二节 框架标记构式及其整合等级

性质：介于自由短语与固化短语之间，旧称"类固定短语"。文炼（1988）首提；周荐（1997）定为中间单位；张斌（2002）指"固定语型+可变替换""格式义+具体义"；王吉辉（2009）归为板式固定语。

**一、"没X没Y"（前置标记）**

- A：X、Y 具体，客观陈述，作谓语（没月没星）。
- B：X、Y 抽象，两项转指整个认知域（没才没貌、没钱没势）。
- C：X、Y 原为并列式复合词，拆开嵌入，语素黏着（滋味→没滋没味），与"没有XY"对举可见其变。
- D：否定义消解，专指化、熟语化（没大没小）。

**二、"X前X后"（后置标记）**

- A：方位义为原型，X 为本义，类推性强（山前山后）。
- B：空间转指时间，属本体隐喻（ontological metaphor）；X 为事件动词或事件名词（会前会后、雨前雨后）。
- C：X 为自主动作动词，前、后虚指（跑前跑后）。
- D：固化成语，取方位隐喻义（跋前踬后）；另一类原文未展开（待核对）。

**三、构式语模**：2+2 韵律，能产，近 50 种。前置"X…X…"（爱…不…、半…半…、现…现…），后置"…X…Y"（东…西…、三…四…）。

### 三、方法与分析思路

1. 先立句法试剂再分级，不以义项直觉代论证。
2. 多维标准打勾成矩阵，使层级可检验。
3. 以点带面：高频词表加词典穷举，控制样本。
4. 平行结构对举：黏合式对"的"字式，构式对"没有XY"。
5. 以连续统取代二分。

### 四、典型案例与语料

1. "洗菜／洗牌／洗钱"——动词义沿隐喻递降而名词义不变，证 B 级半整合。
2. "开车→（他）开的车"——插"的"提取受事，证 A 级低整合。
3. "圆桌会议"——以桌形转指会议性质，浮现"平等"，证 C 级转喻。
4. "没滋没味"——"滋味"拆开入框，整合痕迹最显。

### 五、术语清单

| 术语 | 释义 |
|---|---|
| 概念整合（conceptual blending） | 择取两域部分意义合成复合概念结构的过程 |
| 浮现意义（emergent meaning） | 整合新生、不能由成分义相加得出的意义 |

- **陆俭明《现代汉语语法研究教程》**：变换与语义特征的路数同源，目的由分化同形转为排序同级。

### 七、总结复盘

#### 本章要点

- 整合＝框架作用于元素，产出浮现意义；构式语法与整合理论是"结果"与"过程"一体两面。
- 整合度可句法测试：述宾看"的"的插入与后附，黏合定中看四条标准，均呈 A—D 连续统。
- 虚化途径定等级：本义<引申义<整体隐喻/转喻/抽象融合<熟语专指。
- 框架标记构式是 2+2 韵律的高能产模板，前置"X…X…"、后置"…X…Y"。

#### 易错点/难点

- "的"是试剂不是定义，整合度本身指语义融合程度。
- B 级与 C 级易混：前者一动一名、名词义不变；后者两成分皆虚化或整体转指。
- 黏合定中 B 级 a 类"不能插'的'"源于 N₁ 的分类功能，不等于整合度高。
- "X前X后"分级看方位义漂移（空间→时间→虚指→隐喻），不单看 X 词性。

## 第3章 构式原型与扩展承继

### 一、概念引入

构式（construction）如家族：先有典型成员，再衍生一群面貌相似、功能相近的"子孙"，此即扩展承继。本章追问触发条件、路径与理据。

### 二、核心内容与论点

#### （一）总纲：三类扩展

- 起点是 Goldberg（1995）的"内部承继"。既有研究多归隐喻：张伯江（1999）双及物、高增霞（2006）连动式、张旺熹（2006）"把"字句。
- 作者补一条更隐秘的途径：构件次范畴特征变换亦触发扩展，并牵动事件框架角色指派，故分核心谓词、组配构件、整体构式三类。

#### （二）第一节 核心谓词的扩展承继

**1. "NP+VR"自致使义构式**

- 原型A式＝主体NP＋黏合动结VR：NP为能自主行为的生命体，V为单音节不及物自主动词（哭、跑、坐、躺），R为单音节性质形容词（累、烦、腻），多含消极义。
- 构式义为"非预期的过量后果"，主体兼致使者与被致使者；故无否定式（"没VR"仅用于辩误），不能构成可能式。
- B式：V换及物动词仍不带宾语。一因补语指向施事的述补短语不能带宾语（陆俭明、马真1997）；二因受事在构式语义中无角色，属"构式外成分"。可见论元结构≠构式语义。
- C式：R为非自主不及物动词且带宾语（哭瞎了眼睛），系"NP+V"与"V+NP"经动结式整合。依非宾格假定，"哭"属非作格句、"瞎"属非宾格句；C式与A式仅差R由词换短语。

**2. "V起来"话题义构式**

- 码化"NP+V起来+AP"。谓语说、状语说、情态说均不贴切；作者判为指称性次话题，因AP直陈"V起来"——"她笑起来很好看"≠"她很好看"。
- 来源：起来由位移义经隐喻得起始义；两小句整合后时间因素消除，"V起来"失核心谓语身份，前移为次话题，生浮现意义，表评价，"当……的时候"与假设意味由此衍生。
- 扩展：受事NP构式（话题化，施事退为背景）与施事NP构式；AP指向不改构式义同一性。

#### （三）第二节 组配构件的扩展承继

**1. "一M比一M+VP"递进性差比构式**

- "一M"指特定集合中某一成员，故"一"非真值义，不能换"二、三"。原型靠频率定：时量＞动量＞物量，故A式为时量式。
- A式用有界时段切割无界性状，时间为前景；B式事件本有界，可直接作差比对象，时间退为背景；C式为物量集合，仍受时间制约。
- 三式为隐喻性承继；时间推移是构式成立的条件（项开喜1993）。

**2. "V₁一量V₂一量"构式**

- 来源：条件句紧缩式。原型为施事同一、两量同指、数词限"一"。
- 变异：施事不同一（喂一口吃一口）、一量不同指（砍一棵栽一棵）、数词不同量（来两个杀一双）。同指受预设制约。

#### （四）第三节 整体构式的扩展承继

**1. "A不到哪里去"**

- 构式义：性状程度不超出有限量幅，属主观小量评价。空间义与形容词本不搭，义不可推导，故为典型构式。
- A限性质形容词，具隐性弥散量＋极性静态量，是构式义浮现的关键。CCL检索163例，单音占80%，合基本范畴层次论。
- 后置构件空间义虚化、熟语化，已含程度量，故A不能是状态形容词，不能受程度副词修饰或重叠。
- 溯源：原型为"V不到哪里去"，无平行肯定式"V得到"；中间C式由动作性弱的动词（撒、赖、变）构成，重新分析为"赖/不到哪里去"，A遂进入。

**2. "能性否定+疑问代词"构式群**

- 能性否定即"V不C"。疑问代词须蕴含量范畴：哪里、多久、什么、多少；"谁""怎么样"不合。
- 三类：V不了多久（[+持续]）、V不了什么（及物，物类量）、V不了多少（真值数量，最抽象）。
- 隐喻承继：具体量映射到性状域，V换为A，见能产性。强弱：A不了多少（几近开放）＞A不到哪里去＞A不了什么（限双音节）。
- 共性：义同一；A蕴量级差，常引差比句；积极义形容词远多于消极义。
- 理据：主观性（Lyons 1977）——"不"表主观意愿，与"没"的客观陈述相对；语用上否定句中代词只作非疑问用法（陈振宇2010），由预设推出有限。

### 三、方法与分析思路

以语料频率定原型；用替换法换谓词、量词、疑问代词；以最小对立反证限制；用重新分析与切分证虚化与承继；先立理据再演绎构式群验证。

### 四、典型案例与语料

1. "老大娘天天想儿子，天天哭，哭瞎了眼睛。"——C式典型，证两表述经动结式整合。
2. "臭豆腐闻起来臭，吃起来香。"——AP分述两种状态，证"V起来"为次话题。
3. "名气一天比一天大，酒量一天比一天小。"——A式时量，证有界时段切割无界性状。
4. "就算有武功，也好不到哪里去。"——空间义虚化为程度量，证构式义不可推导。

### 五、术语清单

| 术语 | 释义 |
| --- | --- |
| 扩展承继（extension inheritance） | 原型经构件替换衍生变式并保留理据联系 |

## 第4章 句法同构与多义解读

> 对应原书第一节至第三节；书籍页码待核对。

### 一、概念引入

形式与意义并非一对一：同形可多义，异形可同义。"异构同义"易识，"同构异义"却常被误判成不同结构。判据是 Goldberg 的最大理据性原则：句法、语义皆有联系，构式即有承继理据。全章以三类同构演示。

### 二、核心内容与论点

#### 第一节 实体、事件、时段的数量同构

- **改名即立论。** 物量、动量、时量改称实体、事件、时段量词（entity／event／temporal classifier），因三者共有个体化（individuation）功能。
- **统一格式。** NP(受)+VP(t)+QM。A 物量（"新书竟然弄坏了两本"）、B 动量（"这座楼烧毁了三次"）、C 时量（"县城连续攻打了三天"）。共性：受事前移作话题、QM 回指成焦点、V 带结果补语与"了"。差别在时间：A 只含一事件一时段；B 可含多事件多时段；C 以延续时间本身为计量对象。
- **量词同一性。** Lyons（1977）谓实体量词提供个体化原则；大河内康宪（1993）谓其使类名可指称个体；刘丹青（2008）谓主功能即个体化。刘辉（2009）推及事件量词，为事件类别指派个体时段；时段单位则纯属人为规定。
- **VP+QM 的同构性。** 悖论：数量词判为体词性，结构却摇摆于述宾、述补。丁声树等（1961）"准宾语"（quasi-object）→赵元任（1979）"自身宾语"（cognate object）→朱德熙（1982）以"买一本／买了一本／买一本书／一本也没买"证同构。驳"头不能论次"：非自由形式≠句法形式，语义选择≠结构关系。
- **同类演绎。** "一量+都/也+否定"居主位，否定最小量即否定全量；"V₁一量 V₂一量"居宾位，表行为惯性与消极评价。量词可换而构式义不变。

#### 第二节 黏合定中 NN、NV 的称谓同构

- **来源之争。** 王力（1945）欧化说：汉语无 action-nouns，NV 系对译英文（administration of industry and commerce→工商管理），贺阳（2008）以报刊语料支持。作者主外因通过内因："牛羊供应所"（《宋史·职官志四》）、"盐引批验所"（《清史稿·职官志三》）证 NV 古已有之，原为官职机构称谓。
- **句法属性。** V 为行为动词，N 为受事或产物。NV→VN 受 N 具体性制约："制造汽车"合格，"?"制造船舶"不合格，补足修饰语又可（制造高吨位远洋船舶）。定语位只需区别性，宾语位需受事性（陈平 1994），故非换序。
- **构式赋义。** NV 属在线构成，由称谓性 NN 类推。陆丙甫（1988）"称谓性／描写性"对应"黏合式／组合式"；"的"表描写，故黏合式不可插"的"。V 准入：双音、联合式、动性最弱（张国宪 1997）、具事件指称义，效应为"事件性称谓"。
- **指称与整合。** NV 与 VN 指称性两极对立，只宜"进行、从事"类宾语。称谓结构非离散："公路建设"2700 万字语料 178 例，仅 1 例离散。

#### 第三节 述补 VR 黏合两字组的虚实同构

- **切口。** "得"的隐现分黏合式与组合式，郭继懋、王红旗（2001）以"规约性／偶发性"解释，属"重度—标志对应律"的象似动因。"气死周瑜"表死亡、可插"得/不"；"气死我了"表程度、不可。旧说分归动结式与动程式，作者视为虚实同构："死"由生命域隐喻映射至程度域。
- **鉴别标准。** 语义：V 本义或引申、自主及物强弱；R 本义或引申、有无语义指向。句法：能否插"得/不"；能否进"一A就B"或分解。
- **范围。** 《八百词》单音动词 155、形容词 39，可作动结式第二成分者 28，剔"了、见、多、少"后得 24。
- **三级整合度。** VR₁ 低：皆本义，致使义，R 指向受事或施事，三项测试皆通过。VR₂ 中：R 虚化、V 引申、宾语抽象，结果义分达成（着中到）、定止（定死住）、透彻（穿破透）、损失（坏掉走），少数能插。VR₃ 高：词汇义几近消失，附着义分实现（掉着住）与程度（坏死透），三项皆不通，R 无指向，近准体标记。
- **虚化机制。** 内外因双向：环境激活潜在语义因子（"堵死通道"激活"死板"义，"看破红尘"经本体隐喻激活"破除"义）。构式成型后具开放性，双音可准入，多表消极义。

### 三、方法与分析思路

1. 先立同构再谈多义，以理据性而非形式相似为判据。
2. 术语重命名，把三类量词收拢到"个体化"。
3. 替换测试：换量词、换词类，看构式义是否守恒。
4. 语义与句法双鉴别，三项句法测试作整合度标尺。
5. 封闭语料定范围，以频率检验；认知解释用隐喻、框架、象似动因。

### 四、典型案例与语料

1. **"新书竟然弄坏了两本"／"这座楼烧毁了三次"／"县城连续攻打了三天"**——同格式三种量词，证数量同构，差别只在时间显隐。
2. **"制造汽车"合格，"?制造船舶"不合格**——证 NV 非 VN 换序，受 N 具体性制约。
3. **"气死周瑜"可插"得/不"，"气死我了"不可**——证同一形式的虚实对立，即同构多义。
4. **"看穿→看得穿"与"?揭得穿"并存**——证 VR₂ 虚化参差，测试呈倾向。

### 五、术语清单

| 术语 | 释义 |
|---|---|
| 同构（isomorphism） | 形式相同而功能、语义有系统对应 |
| 最大理据性原则（Maximized Motivation Principle） | 句法、语义皆有联系则构式有理据 |

原笔记此节仅列"待核对"占位，以下为整理者补充。

## 第5章 构式赋义与话语功能

### 一、概念引入

构件组配产生超出部件之和的"浮现意义"，即构式赋义；说话人挑中某说法，因该构式自带话语功能。本章收回前几章的典型构式，提炼其义、归纳其用。

### 二、核心内容与论点

#### （一）总纲

- 根基是格式塔心理学，"整体大于部分之和"；沈家煊（2006）"最美的美女"顺口溜说明美在整合。
- 程序（Evans & Green 2006 归纳 Goldberg）：先论构式理据、提炼构式义；再依"基于用法的模型"归纳话语功能。

#### （二）第一节 主观量评价

**1. "A 不到哪里去"**

- 依托"主观性"（subjectivity，Lyons 1977／沈家煊 2002）：情感、视角、认识；主观量的动因是**视角**。
- 构式义：**评述性的有限程度量**——认定主体不可能达正/负极致，只在有限范围。范伟（2010）归认识情态。
- 语用预设：**承认 X 所表现的性状，但认为其程度量有限**。适切语境：对方评价超出说话人认定范围，遂据理据示其过量。

- 功能三形式：
  - **常式**：转折/让步为优势式，因预设即"承认—转折"；因果、条件式由二者整合而成。
  - **差比**：程度量判定关联差比，故常引进比较对象——逻辑推论或"比+NP"（"人比猴子聪明不到哪里去"）。
  - **紧缩**：高频→固化，同现成分（重复 A、"也"、"再"）同步固化，成"A 也…"式；前 A 具**次话题**性质。

**2. "NP(受)+VP(t)+QM"**

- 由"VP(t)+QM+NP"变换而来：QM+NP 分裂、NP 前移话题化，QM 成焦点。构式义：**对已然事件计量状态的主观化评述**。
- **非常量与发活动因**：计量经认知"过滤"分常量/非常量；常量为常态→无诱因，非常量→激发动机。
- **主观小量与主观大量**：客观量与主观评价可背离，体现为具体量背后的**抽象价值量**（"一句顶一万句"）。

#### （三）第二节 感受性评价

立足"评述"这一言外行为：基于识解表达观点、态度、评价。

**1. "NP+VR"自致使义**

- 背景：动结式术语首见吕叔湘《现代汉语八百词》（1980），近于朱德熙（1982）黏合式述补结构；四角色为致使者、方式、被致使者、结果，原型是他致使（X→Y）。
- 推进：有他致使必有**自致使**，二者合一（"他跑累了"）；理据取自"自动词/他动词"与"反身代词"的平行。
- 条件：NP 为能自主行为的生命体；V 多为单音节不及物自主动词；R 多为单音节性质形容词，多含消极义。
- 关键判断：属**弱致使义**——动作与结果无直接因果（"坐"不致"烦"，"久坐"才致），须有表"过量"的语境信息（"两个时辰"为时间量）。由此得**过量后果**与**非预期**两特征。构式义（原文截断，待核对）：主体因动作过量而致自身出现非预期消极状态。

**2. "V起来"话题义（NP(受)+V起来+AP）**

- 功能：对惯常性活动状态引发的感受加以评述，非现实事件，无时间因素。
- 命题特征：常被比附英语中动句的**通指性**（generic，曹宏 2005）；作者以统计反证——NP 通指仅 13%，定指/特指 87%，通指非必要条件。
- 表述特征：AP 多为朱德熙（1956）的形容词复杂形式，与评价义匹配。强化理据两路：**语境凸显理由**、**AP 引进比较**；理据可视为"致使因"，可改写为"使"字句。

#### （四）第三节 消极义评价

- 发活动因：常态无可评，**非正常状态**才激起评述，机制与**移情**（empathy，Kuno 1987）相关。旁证：吴葆棠（1987）统计"把 N+V 了"62 例，61 例动词表违愿或丧失。

**1. "爱 V 不 V"**

- V 前后同形，多单音节。构式义：表两种动作任凭对方选择，兼传不满；两项极性对立不能同真，只共现于**选择性语境**。
- 判构式标准：此语义与语用信息无法由成分推知——**不可预测性**。
- 整合路径（回应江蓝生）：先"截搭式"整合，从"爱 V 就 V，不爱 V 别 V"各截一段；再**构式类推**，使役、心理、消现动词进入而不可还原。

**2. "V₁一量 V₂一量"**

- 来源：篇章中条件复句的整合，两"V 一量"含条件—结果关系，表惯常现象；属**非现实句**：无时间因素、不带体标记。
- 功能：对该行为惯性的**消极评价**。V₂ 多含消极义（散、忘、砍、丢）；更有力证据是 V₂ 本无消极义者（"买一副丢一副"）仍获消极解读。

### 三、方法与分析思路

1. 先义后功：以不可预测性证构式成立、提炼其义，再归纳功能。
2. 变换与最小对立："阳光灿烂，冷不到哪里去"对"要说冷，也冷不到哪里去"，证因果/条件式非原型。
3. 预设解释优势句式，频率—固化—扩展解释紧缩式；13%/87% 推翻通指必要。

### 四、典型案例与语料

1. "就算他是博士，也高明不到哪里去！"——证"承认性状、否认极致"的预设。
2. "败者固是全军覆没，但胜者也好不到哪里去。"（古龙）——证差比对象是程度量判定的延伸。
3. "小和尚坐了两个时辰，就坐烦了。"——证弱致使：致因是"两个时辰"的过量，非"坐"。
4. "扎一捆散一捆。"——证该构式表反复惯性、非一次性事件，含消极评价。

### 五、术语清单

| 术语 | 释义 |
| --- | --- |
| 主观性（subjectivity） | 话语中说话人"自我"的印记，含情感、视角、认识 |
| 识解（construal） | 说话人对情景的特定观察与组织方式 |
| 通指性（generic） | 命题不指向特定个体而表一般情况 |
| 移情（empathy） | 说话人认同于句中事件的某一参与者 |
| 弱致使义 | 动作与结果无直接因果、须借"过量"信息成立 |
| 非现实句 | 表惯常事件，无时间因素、不带体标记 |

### 六、与其他书籍的联系

- 朱德熙《语法讲义》：援引两处——朱德熙（1982）黏合式述补结构界定动结式；朱德熙（1956）形容词简单/复杂形式之分支撑评价义。
- 陆俭明《现代汉语语法研究教程》："弱致使义"可与语义特征、配价、语义指向对读。（整理者补充）
- 温格瑞尔《认知语言学导论》：原型范畴、识解、图形—背景为原型扩展之来源。（整理者补充）
- 张敏《认知语言学与汉语名词短语》：本章引"理想化认知模式"即注"参见张敏 1998"。（整理者补充）

### 七、总结复盘

**要点**

1. 赋义＝概念整合的浮现意义；功能＝识解驱动的构式选择。
2. 三类评价动因各异：主观量源于**视角**，感受性源于**感受**，消极义源于**异态**与移情。
3. "A 不到哪里去"核心是"承认性状、否认极致"。
4. 自致使"NP+VR"是弱致使：须有"过量"信息，后果消极且非预期。

**易错点**

1. 把"A 不到哪里去"当否定结构，忽略其评述性与主观性。
2. 把自致使致因误认作动词本身，实为"过量"的量范畴信息。
3. 盲从"汉语中动句通指"之比附，忽视 87% 的 NP 为定指/特指。

## 第6章 语用心理与语境适切度

### 一、概念引入

人为何开口？作者答"有感而发"：事件落在心理预期"尺度"之内不值得说，超出（反预期）才有发活动因。由此提出"语境适切度"（contextual appropriateness）——构式所适用的特定语境，追问"什么语境选什么构式"。全章以三案例演示句法—语义—语用三层贯通。

### 二、核心内容与论点

#### （一）从语义三角到语用三角

- **语义三角**（semantic triangle，Ogden & Richards 1923）：能指—概念、概念—所指为实线，能指—所指为虚线；指称实为"能指—概念"关系，"鲸鱼""飞碟"即其证。
- **语用三角**（pragmatic triangle）：同构映射到语用域，能指=话语，所指=事件，中介换为对"情境"（scene）的"识解"（construal），即 Lakoff（1987）的 ICM。视角、情感有别则表述有别（"横看成岭侧成峰"）。故范畴化与表述皆为主观化产物。

#### （二）言语行为与心理预期

- Searle 承 Austin：交际的最小单位不是词或句，而是**言语行为**（speech act）。
- 作者细化 Searle 五类之首"阐述类"：叙述说"事"、论述说"理"，并补第三类——**评述**：基于识解表达观点、态度、评价，主观性鲜明。全章立足"评述"。
- 超预期属**认识情态**（epistemic modality），其主观化后果之一即反预期表达式构式群。
- 认知基础借 Talmy（2000）**事件框架**（event frame）：路径、因果链、循环、参与者互动、相互关系，靠**关联性原则**互激；超预期即框架内匹配、合理、协调性偏差。

#### （三）反预期表达式三型

1. **匹配异常**：身份与行为不匹配。"都 NP 了，还+VP（否定）"——"都"轻读为语气副词表始料未及，"了"为了₂，前为依附小句，后为语用否定。
2. **因果异常**：行为与结果不合理。重动句 S+VP₁+VP₂（VP₁ 具次话题性），分评述行为本身（"打篮球打得好"）与评述后果（"挖井挖出一坛金子"）。
3. **事理异常**：行为与背景不协调。"大 Nt 的+V什么 N？"——"的"确认时间背景，"什么"表否定，反诘整体表否定。

#### （四）隐性语义等级序列的激活

- **顺序范畴**分显性（语序，属句法临摹，体现**象似性**；戴浩一 1988、袁毓林 1999）与隐性（NP 在构式中被激活的语义等级序列，靠形式触发加规约认知）两类。
- **"都 NP 了"**：邢福义（1984）最早描写"NP 了"，作者辨两式："大姑娘了，懂规矩了"（正预期）与"都大姑娘了，还这么不懂规矩"（反预期）。NP 须具 **[+顺序]**；准入三层排除：离散物名、泛义指人名、序列初始端者（"小孩、小兵"无"落差"）。
- **触发≠激活**：形式只是"开关"，"通电"才是规约清单的比配。触发三点：了₂ 暗示序列、后句 VP 提示匹配行为类、"都/还"明示预设。
- **否定性"连"字句**：刘丹青（2005）——NP 居可能性低端而词汇义高端，预设"极不可能真"与断言"事实为真"反差生强调。作者补：否定式中 NP 反居**可能性高端**，断言"最可能者竟为假"；且否定式偏消极义，褒扬可容忍、贬斥受审视，故须把 X 外扩为先行小句以确认定指身份。
- **量级模型**（沈家煊 2001）："学历—写作能力"矩阵分三区——不合常理（有诱因）、出乎意料（动机最强）、不言而喻（不值得说）；**焦点—背景**（Talmy 2000）说明从句为背景、主句为焦点。

#### （五）[±积极]语义特征

- 语义特征分层：依附功能类的（[±述人]、[±自主]、[±量度]）为一层；跨范畴的 [±积极]（旧称褒贬义）为更高层，是句法—语义"接口"。
- **形容词使动**（功能漂移，张伯江 1994）：词典统计 82 例，积极义 65 例（81%），消极义 10 例（14%）。消极义者及物性极弱："疏远了朋友"是"对朋友疏远"非"使朋友疏远"；"繁荣了市场"成立，"萧条了市场"不成立。历时亦同此倾向且多对举。
- **"看你 A 的"**：构式义同质（对反预期状态的否定取向），语用义两极分化：A 消极→慰藉爱怜（正值），A 积极→质疑斥责（负值），呈**反向共变**。理据：人心有"度"，偏离即"过度"；过度消极生悲悯，过度优越生不以为然。
- 同类：作格句"沉了船、死了父亲"多纳消极义动词。

### 三、方法与分析思路

三角推演（语义域→语用域）；同族辨异（"NP 了"两式最小对立定构式义）；触发—激活两段模型；矩阵建模（把语感转为可接受度分级）；词典统计配反义类比。

### 四、典型案例与语料

- **"都大姑娘了，还这么不懂规矩。"**——证明反预期依附小句：了₂ 触发序列，后句否定承载评述。
- **"老王连老鼠肉都敢吃。"**——证明肯定式"连"字句：NP 居可能性低端，预设与断言反差生强调。
- **"瞧你美的！这事可没那么顺当。"**（李佩甫《羊的门》）——证明 A 表积极义时语用义转负值。

### 五、术语清单

| 术语 | 释义 |
| --- | --- |
| 语境适切度（contextual appropriateness） | 构式义所制约的特定话语功能及其适用语境 |
| 反预期（counter-expectation） | 状态超出社团规约认知的"尺度"，亦称超预期 |

原笔记此节仅列"待核对"对读入口，以下为整理者补充：

### 七、总结复盘

**要点**

1. 反预期是语用驱动核心：合尺度不说，超尺度才说；三型对应匹配、因果、事理三类偏差。
2. 解读"都 NP 了""连"字句须分形式触发与认知激活，后者靠"NP—应有状态"清单。
3. 顺序范畴有显隐两半：显性靠象似性，隐性靠规约认知；[±积极]则投射到词类功能、语用心理与句式准入。
4. 落点是语境适切度——构式研究终须回答"何时用何式"。

**易错点**

1. "都 NP 了"的"都"是语气副词（可隐去），"了"是了₂ 非完成体了₁。
2. "触发≠激活"：见"了₂""连…都"只是开关，解码取决于听者是否持有匹配清单。
3. "连"字句肯定式 NP 居可能性低端、否定式居高端，方向相反。
4. 82 例仅为词典静态样本，引入频率后比例更悬殊。

## 第7章 参数变量与构式变异

### 一、概念引入

"参数"借自数学，指可在一定范围内变化的量。构式由若干"构件"配置而成，构件变动并积累成质变，整个构式便改形——此即**构式变异**。本章以"有"字构式、2+1 韵律框架、差比与自致使三案，说明语义、韵律、语境三条通道如何驱动变异。

### 二、核心内容与论点

#### （一）总纲：从构件到参数变量

- **构件**即具一定句法语义属性的**语块**（chunk），源出陆丙甫（1985）"板块组合"、吕叔湘（1979）"只停大站"的阶层分析。
- 构件可变，先在同一构式内生成家族相似性成员，属**内部承继**；量变至质变则生**外部承继**，即 Goldberg 的"多重承继"。故构件可演绎为**参数变量**。

#### （二）第一节 多义范畴衍生："有"字构式

- 语料：500 多个固定"有+N"中，N 或整体表积极义者占 70%。
- **原型义**：许慎"不宜有也"不可通；《广雅》"有，取也"；古文字作"从又持肉之象"（陆宗达 1981）。上古肉难得，故本义为"拥有（美好的物品）"。
- **分化**：实义二——拥有（本义）、存在（引申）。存在属客观范畴，拥有属主观范畴；所指范围前者大于后者。二者投射为**领有句／存现句**。
- **判定**：传统看主语**生命度**（处所主语强制表存在）；但指人主语未必表拥有——"老王有钱"取拥有，"老王有病"取存在，取决于宾语 **[±积极]**：积极激活"拥有"，消极激活"存在"，是为认知"默认值"。
- **整合**：积极义"有+N"整合度高，已形容词化，可加"很"（很有魅力）；消极义者仍为述宾，不能加"很"。此即**压制**（coercion）：中性名词进入亦得高程度义，解正明（2007）称"非常量"。理据仍是原型义与**期望值**。

#### （三）第二节 韵律框架变形：2+1 与复合化

- 双音动+双音名有两解：述宾（"制造汽车"）、偏正（"消防汽车"）；两兼者为**同形异构体**（"出租汽车"），构成非离散连续统。
- **2+1**（V双+N单）黏合紧密，为三音节复合词主体（周韧 2006）；作者（2006）提出"**前松后紧**"：单音节居前结合松、居后结合紧。
- **连调**：2+1"雨伞厂"只作顺向（35-5-213）；1+2"小雨伞""买雨伞"可作逆向（21-35-213）。
- **音步**：**三摩拉调**（213 等）有标界作用；"雨伞厂"仅末字取 213，为稳定单音步。故 2+1 是**韵律词**、1+2 是**韵律短语**（王洪君 2000）。
- **两效应**：**隐退**（偏正显、述宾隐，"出租车"锁定偏正）与**复合**（固化为类名，不可扩展）。
- **准入**：动词须能修饰名词并有分类功能，多为**联合式双音动词**（设计、检测），因动性弱化而述谓性转描写性（王灿龙 2002；张国宪 1997）；名词多联合式或名量式，语义抽象，入框架时压缩为黏着单音节（片、金、件、稿），属"削足适履"。
- **分类性**："复印文件→复印件"成立（对"原件"），"学习文件→*学习件"不成立。所谓"约定俗成"实即范畴化认知的**规约化**。

#### （四）第三节 语境特征消长

- **量级序列缺失**："一M比一M+VP"本表递进差比（A 式时量"一天比一天"、B 式动量"一次比一次"，另有 C 式，依"最大理据性原则"承继）；量级信息一消失，则边缘化为**遍指性非差比义**"一个比一个+VP"，义为"个个都 VP"（"一个比一个酷"）。
- **致使因凸显**：NP+VR 自致使原型 A 式（"小和尚坐烦了"）→V 扩展生 B 式（"小伙子唱哭了"）→受事指派为致使因并话题化、原施事移至句末，成 **NP(受)+VR+NP(施)**（"这一大盆脏衣服洗累了妈妈"）。
- **变异条件**：致使因须有足够信息量，光杆名词不合格，信息越充分合格度越高（电影＜恐怖电影＜这么毛骨悚然的恐怖电影）；判据是含"**过量**"信息——"一大盆"表物量，"这么大场面"表程度量，正合该构式"非预期过量后果义"。

### 三、方法与分析思路

以"构件—参数"为统一装置分层检验：语义层看词义特征如何定构式解读；韵律层以连调、摩拉、音步作客观试剂；语境层看信息特征消长如何推移构式边界。手段：最小对立、同形异构体辨异、词典统计、反义类比、可接受度梯度。

### 四、典型案例与语料

- **"老王有钱／老王有病"**——证明"有"字句因宾语[±积极]分取"拥有/存在"，生命度不足以判定。
- **"很有魅力"／"很有毛病"**——证明前者已形容词化，后者仍为述宾，整合度有别。
- **"出租汽车→出租车"**——证明 2+1 框架的隐退与复合双效应。
- **"这一大盆脏衣服洗累了妈妈。"**——证明致使因话题化须带"过量"信息。

| 术语 | 释义 |
| --- | --- |
| 参数变量（parameter variable） | 由构件演绎而来、可变且能触发构式变异的因素 |
| 构件／语块（chunk） | 具特定句法语义属性的组配单位 |

原笔记此节仅列"待核对"对读入口，以下为整理者补充：

- **朱德熙《语法讲义》**：述宾/偏正识别与朱书结构关系分析一脉；"有"字句之分可与朱书存在句对照。
- **陆俭明《教程》**：同形异构体即歧义格式，与陆书变换分析、歧义分化同题。

### 七、总结复盘

**要点**

1. 变异总机关是"构件即参数"：语义默认值、韵律框架、语境信息任一变动皆可推移构式。
2. "有"的拥有/存在二解由宾语[±积极]默认激活，并在句法上显形（能否加"很"）。
3. 2+1 与 1+2 的对立有语音实证（顺向/逆向连调、三摩拉标界）。
4. 变异有门槛：致使因须携"过量"信息，不足则不成立。
5. 内部/外部承继之分，把原型扩展与构式变异纳入同一演化链。

**易错点**

1. 勿以主语生命度一刀切判"有"义——只有处所主语才强制表存在。
2. "N单"非天然单音成分，而是双音名词被 2+1 压缩之果，故多为黏着语素。
3. "一个比一个+VP"已非差比，勿按递进义解；动因是量级序列信息缺失。
4. 致使因话题化非自由移位，受信息量制约，光杆名词常不合格。

## 第8章 结语和思考

### 一、概念引入

本章把全书六个论题收成一张"承继网络"的纲领图，同时坦白只走完第一段路——内部承继，并把下一阶段目标拆为三层理据。读法上应视其为全书索引加研究计划。

### 二、核心内容与论点

#### （一）学术背景

承格语法而来，故重语义结构；又作为认知语言学分支，视语法为含心智、感知与运用的综合能力。四源：Fillmore 立语义建构；Kay & Fillmore 由习语确立"形义匹配体"；Lakoff 的"完形"思路成方法论核心，构式系统为原型与次范畴的辐射状扩展；Langacker 视构式为象征性集合。

#### （二）六条主要结论

1. **概念整合与框架构式**：整合是过程，构式是结果；分词语、类固定短语（框架构式）、常见构式三层。个案：V+N、N双+N双。
2. **构式原型与扩展承继**：Goldberg（1995）重内部承继，即能产性；原型经构件扩展向家族成员映射。三路径：核心谓词、组配构件、整体构式。
3. **句法同构与多义解读**：形式与意义一对多；Goldberg（2006）以形式—功能匹配立论，**最大理据性是判断同构的依据**。个案：数量同构、NN/NV 称谓同构、VR 虚实同构。
4. **构式赋义与话语功能**：源自 Lakoff 认知语义学与完形感知；构式义即构件组配之果，即**浮现意义**（emergent meaning）；说话人依识解选构式，因各构式有特定话语功能。
5. **语用心理与语境适切度**：形式隐含语义，语义体现语用；作者创**"语境适切度"**，指构式所适用的特定语境。三线索：反预期、隐性语义等级、[±积极]语义特征。
6. **参数变量与构式变异**：构件可变，演绎为参数变量；变异由量变到质变。三路径：多义范畴衍生、韵律框架变形、语境特征消长。

#### （三）考察范围：内部承继与外部承继

- **内部承继**：原型与其变式之间，体现隐喻映射的能产性效应。
- **外部承继**：不同构式之间，即"多重承继"网络。作者判定此层更重要：其初衷是为全部构式建网络、列理据"清单"，作类型学归纳。
- 本书基本限于内部承继：理论对多重承继仍停在原则性思考与示例考察，西方学者擅立框架而常难有始有终；汉语研究多为单个构式的个案描写，仍是"游击战"，传统句式研究只做"分析"，未从"整合"看整体语义与语用心理。仅第三章"能性否定+疑问代词"系列、第七章反预期系列触及外部承继。

#### （四）后续思路：理据的三个层级

理据有层次：上位制约下位，语用、语义、句法由表及里。

1. **语用驱动（最高、最深）**：语言是交际工具，故语用驱动是编码的根本动因。旧信息在前、新信息在后可解释话题前置与句末焦点，却不足以解释全部语序，遂引入陆丙甫（2005）"可别度领先"：可别度即可识别的程度（源自 Comrie 1979 生命度、Lambrecht 1994 的 identifiability）；左项可别度高于右项即语序自然方向，实质是"以已知解未知"。同层理据另有时间顺序（戴浩一）等。
2. **语义结构（中间层）**：以致使范畴为例。使成情景由"成因"与"成果"合成，含两个事件、事件间为"作用—效应"关系，含四角色：致使者、致使方式、被致使者、致使结果；覆盖句法标记句、格式句、使动句三类。启示：**一个语义范畴对应的不是单个构式，而是一批构式**，这正是承继链接的理据。汉语已有时间、空间、数量、领属、情态、体貌、程度等范畴。
3. **句法形式（表层）**：特指有区别性特征、能起链接效应的形式。典型是"的""得"的隐现，各造成黏合式与组合式对立："得"字句的分工即因果之别——规约性因果（"老王睡着了"）客观性强，用动结式；偶发性因果（"老王在公园里睡得不会说话了"）主观性强，用带"得"状态补语。这是因果两事件距离远近的句法临摹，属句法相似性，并承载反预期心理。

### 三、方法与分析思路

- **先总后划界**：以六论题作结论，随即声明范围与局限。
- **术语分层**：内部/外部承继二分，理据三层递降，使"承继网络"可操作。
- **以个案证类**：每论题配若干构式个案，并借 Comrie、Lambrecht、陆丙甫等理论落地。
- **自我限制式论证**：承认"游击战"，把局限转为课题。

### 四、典型案例与语料

1. "老王睡着了。／老王在公园里睡得不会说话了。"——规约因果用动结式，偶发因果用带"得"状态补语。
2. "船上无线电的报告使他们忧虑。"——特定句法标记构成的致使句，四角色齐备。
3. "客人来了。／来了客人。"——通指名词主宾位置的定指差异。
4. "什么都没说。／没说什么。"——疑问代词在否定词前后分表全量与部分量。

### 五、术语清单

| 术语 | 释义 |
| --- | --- |
| 内部承继（internal inheritance） | 原型与变式之间的承继，体现隐喻映射的能产性 |
| 外部承继（external inheritance） | 不同构式之间的承继，即多重承继网络 |
| 浮现意义（emergent meaning） | 构件组配后新生的整体意义，不等于部分之和 |
| 语境适切度 | 某构式所适用的某类特定语境，作者自创 |
| 可别度（identifiability） | 指称成分易被识别的程度，含定指性与生命度 |
| 黏合式／组合式 | 定语或补语与中心语结合紧松的两种格式，常由"的""得"标记 |

### 六、与其他书籍的联系

原笔记此节仅列"待核对"，以下为整理者补充。

- 与 Goldberg 原著：内部/外部承继、多重承继、最大理据性原则皆出自其 1995、2006 两书，本章属引申。
- 与朱德熙《语法讲义》：黏合式与组合式定语、"的"的隐现是其经典论题，本章提升为"句法形式理据"。
- 与张敏、陆俭明：距离动因与象似性可解"得"字句；语义范畴、配价与变换为"语义结构理据"层提供描写手段。

### 七、总结复盘

**本章要点**

1. 六论题连成一链：整合→原型变式→同构多义→话语功能→语境选择→构式变异。
2. 承继分两层，外部承继才是最终目标；本书自认限于内部承继。
3. 理据分三层且相互制约：语用驱动→语义范畴→句法形式。
4. "一个语义范畴对应一批构式"是串起零散个案的关键判断。

**易错点／难点**

1. 把内部与外部承继当成同一层次，或把三层理据读成并列清单（原文强调上位制约下位）。
2. 把"的""得"的隐现当作单纯省略，实为功能对立。
3. 全章页码原笔记均标"待核对"，引用前须回查。

## 全书复盘与知识定位

### 本书在五本书体系中的位置

本书是"构式语法"一支在汉语研究中的系统实践。其理论前提可追溯到《认知语言学导论》第5章（框架、脚本、构式）与第6章（概念整合）；其承继网络与原型范畴观，可与《认知语言学导论》第1章互参；其个案分析所依赖的汉语语法描写框架（述宾、述补、连谓、主谓等），来自朱德熙《语法讲义》；其配价、语义指向、变换分析等操作手段，来自陆俭明《现代汉语语法研究教程》；其对"的"字结构与定语语序的讨论，与张敏《认知语言学与汉语名词短语》形成同一问题的构式视角与象似性视角的互补。

### 全书要点回顾

1. 构式是形式与意义的配对体，具有独立于词汇的构式义；Goldberg 1995 与 2006 两阶段的重心从"构式独立性"转向"承继网络与使用频率"。
2. 词语复合存在整合等级，概念整合与框架构式可解释复合词的语义生成。
3. 构式原型确立后，扩展承继沿"原型—变式"网络展开，受语义、句法、韵律多重限制。
4. 句法同构（数量同构、NV 称谓同构、VR 虚实同构）是多义解读的重要来源，需结合构式义与词汇义分化。
5. 构式赋义体现在主观量、感受性与消极义等话语功能上，构式选择即立场表达。
6. 反预期与语用心理决定构式的语境适切度；参数变量（如韵律框架、语义特征）驱动构式变异与分化。
