# 名家论文论证结构、写作技法与研究范式学习手册

## 以四篇汉语语法论文为对象的客观拆解与升级提示

**编写目的**

本手册选取朱德熙《现代汉语形容词研究》、胡裕树与范晓《现代汉语动词的次范畴》、陆俭明《关于汉语词类的划分》、邢福义《说“NP了”句式》四篇论文，逐篇还原其论证链，指出可直接学习的结构动作、证据安排和收束方式，并在每章最后单列“如何升级到当代研究”的批判性提示。

客观拆解部分只回答三个问题：作者从什么现象或争论进入，怎样把问题拆成可以检验的层次，最后依靠什么证据完成分类或规则。升级提示部分讨论语料、方法、理论解释和边界条件可以如何继续推进，不代替论文作者的结论，也不把后出的方法强加给原文。

**阅读路径**

第一至第五章依次处理总览与四篇论文。第六章把四篇论文放在同一组维度中比较。第七章交代版本和材料。附录一、附录二收入两张课件的文字提取。参考文献置于书末。正文中的页码指论文刊载版本或选集版本的印刷页码；无法确认的出版信息不作补造。正文采用上标编号，出处集中列于“注释与出处”。

# 一、四篇论文的共同论证路径

四篇论文处理的对象不同：朱德熙研究形容词简单形式与复杂形式的语法功能差异，胡裕树、范晓研究动词次范畴的分类，陆俭明讨论汉语词类划分的依据和程序，邢福义描写“NP了”句式的构成、功能与限制。它们在选题、理论位置和写作年代上差异很大，但论证展开都遵循一条稳定路径：

> 现象或争论 -> 指出旧说症结 -> 界定对象和研究平面 -> 提出核心标准或功能框架 -> 用最小对比逐层检验 -> 建立分类或规则 -> 处理反例和边界 -> 交代余论或局限

这条路径的价值不在于八个步骤本身，而在于每一步都承担明确任务。现象负责证明问题真实存在；争论负责说明研究位置；界定对象负责控制讨论范围；核心标准负责让分类可操作；最小对比负责把直觉判断转成可复核证据；分类或规则负责给出答案；反例负责防止结论过度概括；余论或局限负责说明还能推进到哪里。

## （一）问题起点通常不是一个空泛题目

四篇论文都没有从“某类词很重要”“某一句式值得研究”直接进入分析。朱德熙先给出简单形式和复杂形式，再把问题限定在语法功能差别。胡裕树、范晓先从词类研究深化到次类、小类的背景进入，再明确本文只讲句法平面的分类。陆俭明从“老大难”历史争论进入，随后把症结归到理论移植和缺少逐词研究。邢福义直接从“大姑娘了”这类可以成句的语言事实进入，以删除“了”后是否还能成立作为分界。

这种起点的共同点，是让读者很快知道本文将改变哪一个判断：不是重复已有分类，而是补上一个尚不清楚的功能差别、分类依据、划类程序或句式条件。

## （二）核心标准必须可以被反复调用

朱德熙以形容词的简单形式和复杂形式为基本对立，再观察它们在定语、状语、谓语、补语四个位置上的分布。胡裕树、范晓把语法功能定义为词在句法结构中的活动能力，并进一步把功能形式具体化为功能框架。陆俭明把词类划分的核心依据收敛到词的语法功能。邢福义以“NP了”的基本格式为入口，通过删除、移位、变换和最小对比辨认语义条件。

这些标准能够支撑整篇论文，是因为它们不是一次性解释，而是可以被不同词项、不同句法位置、不同变换操作反复调用。凡是能够进入同一框架的项目归为一组，不能进入的项目形成对照，结论由此获得可复核性。

## （三）层次分类比一次性命名更有解释力

四篇论文都不满足于给对象贴一个总标签。朱德熙继续区分性质与状态，并考察重叠式在不同句法位置上的附加色彩。胡裕树、范晓从有宾、无宾开始，再按宾语数量、宾语类型和能否单独作谓语逐层下分。陆俭明把词类划分看作多层划分，强调某一层使用某一标准，同时区分词类的语法性质、语法特点和划类标准。邢福义先把“NP了”分成前置和后置两个基本格式，再考察因果、转折、倒置因果、倒置转折等关系。

分层的作用是避免一步分类造成的交叉。一个对象可能同时具有多种特征，若把所有特征并列使用，分类就无法稳定；若先限定层级，再在每一层选择一项主导标准，对象之间的关系就清楚得多。

## （四）反例不是附录，而是论证的一部分

朱德熙讨论重叠式的程度和感情色彩时，没有把“重叠一定加强程度”写成无例外规则，而是区分定语、谓语与状语、补语。胡裕树、范晓把兼类和功能交叉留在分类框架内说明。陆俭明明确承认词不是离散系统，分类后总会留下例外。邢福义用“猪了”“小孩子了”说明缺少推移性的名词不能随意进入“NP了”。

这些反例承担相同功能：它们显示作者已经检查过规则的边界。能解释反例的分类，比只排列典型例子的分类更可靠；能说明反例为何不能进入的规则，也比只列准入条件的规则更完整。

## （五）共通公式的灵活变体

不同论文的推进速度并不相同。朱德熙的文章以大量词项和句法位置展开，重点在功能对立的理论概括。胡裕树、范晓的文章像一份分类方案，先立原则，再逐层操作。陆俭明的文章同时争论、澄清概念和演示程序，理论反思比重更大。邢福义的文章最接近句式专论，格式、关系、语义条件与句法限制依次展开。

学习这四篇论文，不应机械复制同一套目录，而应掌握位置关系：先让问题有来处，再让标准有落点，随后让例证形成对照，最后让反例或局限限定结论。

# 二、朱德熙《现代汉语形容词研究》

## （一）论文任务与问题切口

论文开篇直接交代研究对象和范围：

> “本文拟说明现代汉语里形容词的简单形式和它的复杂形式在语法功能上的区别。”[^1]

这一句话同时完成了四项工作：明确对象是现代汉语形容词，确立简单形式与复杂形式的基本对立，把研究问题限定在语法功能，而不是泛论形容词的意义。作者随后列出简单形式（单音节形容词和一般双音节形容词）以及复杂形式的主要类别，使后续讨论始终围绕同一组对象展开。

这个切口的可学之处，是把一个看似宽泛的“形容词研究”压缩成一组可以判定、可以对比、可以排列的语法功能差异。读者不必先接受一个宏大理论，就能看见论文将要检验什么。

## （二）论证链结构

**结构流程**：界定简单形式与复杂形式 -> 把多个复杂形式归并为可比较的子类 -> 在定语、状语、谓语、补语四种位置检验 -> 把功能差异提升为性质与状态范畴 -> 讨论重叠式的程度和感情色彩 -> 对未尽问题作补充说明

论文不是按“定义、分类、举例、结论”平铺，而是把研究对象放入不同句法位置进行反复检验。以位置为横轴、以形式为纵轴，功能性差异逐渐显现。最后将句法分布概括为性质和状况或情态，形成从形式到意义的提升。

## （三）客观拆解

### 1. 先建立可比较的两端

朱德熙先让简单形式与复杂形式形成对照，再把复杂形式中的重叠式、带后加成分的形容词、复杂并列结构和带程度状语的词组等收拢为一个可观察的总类。这样处理，既保留内部差异，又避免把每一种形式都做成一篇文章。

可模仿的动作是：当研究对象包含多个表面形式时，先问它们是否共享一个可检验的共同属性。若共享，就建立上位对立；若不共享，就在上位对立下继续分层。分类层级由材料之间的关系决定，而不是临时凑标题。

### 2. 用句法位置检查功能差异

论文依次观察形容词在定语、状语、谓语、补语中的表现。形式相同的词，在不同位置上可能显示不同的限制；位置不同，复杂形式与简单形式之间也不一定保持同一种对立。例如“白纸”“白的纸”“雪白的纸”构成一组连续对比；“一朵红花儿”与“一朵鲜红的花儿”则显示复杂形式进入定语后的新限制。

这种写法的优点是使“形式差别”不依赖孤立举例。一个结论至少要经过多个位置检查，某个位置不合预期时，结论就被迫细化。论文因此能够在总对立下继续区分：某些形式在定语和谓语位置上的表现，与在状语和补语位置上的表现并不相同。

### 3. 让语义概括受句法证据约束

论文把甲类概括为表示性质，把乙类概括为表示性质的状况或情态。[^2] 这里的“性质”和“状况或情态”不是从词义表里直接抄来的标签，而是从句法功能差异中概括出来的结果。语义概括放在功能检验之后，论证顺序因此更稳。

学习者可以借此检查自己的论文：如果先宣布某类词有某种语义属性，再用它解释全部句法表现，容易形成循环论证；如果先从分布和变换得出区分，再把语义概括作为对分布事实的统摄，论证会更有约束。

### 4. 用正例、反例和最小对比共同推进

论文常把能说与不能说并列，形成最小对照。例如：

- 白纸 / 白的纸 / 雪白的纸
- 一朵红花儿 / 一朵鲜红的花儿
- 多人 / 很多人
- 少钱 / 很少的钱

这些对比不只是在增加例量。每一组都控制中心语、句法位置或词义的大部分变量，只改变待检验的形式。读者因此可以直接看到差别落在哪个成分上。对于一篇论文来说，这种“最小差别例证”比连续罗列十个同类例句更能说明问题。

### 5. 在总规律中保留附加色彩

论文后半部分讨论重叠式时，继续区分句法位置。完全重叠式在状语和补语位置往往带有加重、强调的意味；在定语和谓语位置则可能表现为轻微程度。[^3] 作者没有把重叠式统一处理成“程度加深”，而是让位置、形式和表达色彩共同参与结论。

这种处理方式对写作的启发很直接：一个形式在语料中有多种用法时，不要急于挑选最能支持预设的用法。先列出不同位置的分布，再判断哪些位置能够共享规律，哪些位置必须另立说明。

## （四）写作技法

**第一，术语先定义后使用。** 简单形式、复杂形式、重叠式、后加成分等概念都在分析前交代，后文不再摇摆。术语稳定，读者才能把不同章节的结论连接起来。

**第二，句式对比承载论证。** 论文很少停留在抽象判断，而是把判断嵌入“能说 / 不能说”“在此位置 / 在彼位置”的对照。对比使论证具有可复核的形式。

**第三，章内推进有回环。** 每一类形式都要经过多种句法位置，而不是只在一个位置得出结论。回环检验使论文能够不断修正上位概括。

**第四，理论概括晚于材料观察。** 性质与状态的区分出现在大量功能检验之后。先积累可观察差异，再给出概括，能降低理论先行造成的选择性举例。

**第五，余论用于限定结论。** 论文没有把讨论直接停在总规律上，而是继续处理重叠式的程度和感情色彩。这种做法显示，补充讨论的作用不是另起题目，而是清理主规律旁边尚未安放的材料。

## （五）原文摘录与可模仿动作

| 原文摘录 | 论证功能 | 可模仿动作 |
| --- | --- | --- |
| “本文拟说明现代汉语里形容词的简单形式和它的复杂形式在语法功能上的区别。” | 用一句话固定研究对象、基本对立、研究平面和任务边界 | 用一段话分别写出对象、对立项、观察平面和本文要回答的问题 |
| “白纸”“白的纸”“雪白的纸”等对比 | 把抽象的形式差异落实为最小差别例证 | 每组证据只改变一个关键形式，并说明这个改变检验了什么 |
| 甲类表示性质，乙类表示性质的状况或情态 | 在句法分布之后作语义概括，使形式与意义相接 | 先写功能检验，再写语义概括，避免用语义标签替代证据 |
| “一朵红花儿”与“一朵鲜红的花儿” | 用同一句法位置中的不同形式揭示限制 | 固定句式框架，轮换待测词项，记录能进入和不能进入的项目 |
| 完全重叠式在状语、补语与定语、谓语中的不同色彩 | 防止把一种位置上的规律扩大到全部位置 | 逐位置归纳，遇到差异就分层，不把局部规律写成总规律 |

## （六）如何升级到当代研究

朱德熙的论文把形式与意义之间的对应关系放到句法位置中检验，其长处是内证清楚、对比集中、结论有层次。若将这一范式推进到当代研究，可以先从语料规模、连续性和解释机制三个方面入手。

第一，典型对比可以扩展为多体裁语料。文学作品、口语转写、新闻语体和网络文本对形容词形式的选择可能不同。若只使用作家例句，能说明语法可能性，却不容易说明使用频率、体裁偏好和历时变化。后续研究可以把可接受性判断与真实语料频次并列，区分“能说”与“常说”。

第二，二分可以继续细化为连续统。简单形式与复杂形式、性质与状态之间可能存在中间地带。形容词的重叠、程度修饰、后加成分和句法位置可能共同构成一个渐变空间。当代研究可以通过多变量统计、聚类或语义相似度分析，检查边界是否稳定，而不是预先假定只有两类。

第三，句法功能可以继续连接到句法—语义界面。除了考察能否进入某位置，还可以追问为什么某一形式在此位置受限：限制来自谓词类型、体标记、程度层级、信息结构，还是名词的个体性？把这些因素显化，能够把功能描写推进为机制解释。

第四，书面例证可以补充心理实验和加工数据。若研究者主张复杂形式在某种位置上更强调程度或色彩，可以通过可接受性评分、反应时或眼动实验检验这种直觉是否稳定，并区分语法限制与语用偏好。

第五，共时结论可以加入历时和方言比较。现代汉语中的简单、复杂形式对立，可能在历史文献和方言中呈现不同发展路径。把某一时期的分布与历时演变、方言差异并置，能够回答形式如何形成、为何在不同系统中分工不同。

批判性提示的核心是：不要因为经典论文的分类清楚，就把分类本身当成终点。经典范式最值得继承的是“让材料逼出概括”，而不是复制具体的二分法。

# 三、胡裕树、范晓《现代汉语动词的次范畴》

## （一）论文任务与问题切口

论文从三十年代末文法革新讨论中的词类问题进入，说明词类研究已经从大类区分深入到次类、小类，而动词数量多、类型杂，在组词成句中有重要作用，因此有必要进行次范畴分类。作者随后立即限定研究平面：

> “动词的次范畴分类问题，可以从句法的、语义的、语用的三个平面进行研究。本文讲的是句法平面的分类。”[^4]

这句限定使论文不至于把句法、语义和语用问题混在一起。它的写作价值在于先承认更广阔的问题空间，再清楚说明本文只处理其中一个平面。这样的自我限制反而增强了论证力度，因为读者知道后续结论应当从句法功能证据中寻找。

## （二）论证链结构

**结构流程**：历史争论导入 -> 说明次范畴研究的价值 -> 限定句法平面 -> 提出功能分类原则 -> 建立功能框架 -> 按宾语类型和谓语能力逐层分类 -> 处理交叉类、兼类和例外

与朱德熙的“形式对立—功能检验”相比，这篇文章更像一套分类程序。作者先规定如何发现功能，再规定在什么单位中确认功能，最后规定如何逐层分类。论文的主要贡献不只在分类结果，也在分类规则的可重复性。

## （三）客观拆解

### 1. 先说明为什么需要“次范畴”

论文没有把动词看作一个无差别的整体。它将动词区分为不同的次类或小类，理由是不同的动词会组成不同句型或句式。分类的目的因此不是给词库做标签，而是解释动词参与句法组合时的差别。

可模仿的动作是：在提出分类之前，先说明分类能够解释什么。若次类差异不能预测组合能力、句式选择或变换结果，分类就容易停留在命名层面。

### 2. 用三条原则约束分类程序

论文提出三条原则：

1. 从形式出发探求功能。
2. 从词组或短语里确认功能。
3. 多角度、多层级分类。

第一条原则处理发现程序。功能意义内蕴，功能形式外现，因此要从可观察的位置、分布和组合形式入手。[^5] 第二条原则规定观察单位：动词的功能一般在静态词组里就能体现，不必每次放进动态句子。第三条原则处理复杂性：动词可以从不同角度分类，但同一角度、同一层级只能使用一个标准。

这三条原则把“怎样看出功能”“在哪里看功能”“不同层级怎样使用标准”分开，避免把分类标准、观察单位和分类层级混为一谈。

### 3. 把功能落实为功能框架

论文反复使用“功能框架”这一操作概念。分类时先设定一个特定词组形式，例如“动词 + 实词”形成动宾词组，再观察不同动词能否进入该框架。能够出现或不能出现在一定位置上的动词，分别聚合成不同次类。

这种写法的好处是可操作性。读者不必只凭语感判断“有宾”与“无宾”，而可以在明确框架中逐词测试。框架还为同类研究提供了可复现的检查表：换一组动词，仍能沿用同一测试办法。

### 4. 先按一个标准分，再逐层下分

论文先按能否带宾语区分有宾动词和无宾动词。对有宾动词，再按所带宾语的数量继续分类；随后处理体宾动词、谓宾动词、双宾动词等。分类过程中，同一层只使用一个主要功能，避免把能否带宾语、能带什么宾语、能否单独作谓语同时压在一个步骤上。

逐层分类能够安放交叉现象。一个动词可能同时具备多种功能，若全部并列，类别会互相重叠；若按层级推进，就可以说明它在第一层属于哪组、在第二层又表现出什么差异。

### 5. 用对比项目显示功能差异

论文中的例证常成组出现：

- 吃 / 病
- 给、送
- 接、收、受
- 借、租
- 睡觉 -> 睡了一觉
- 革命 -> 革他的命
- 吃亏 -> 吃了大亏

这些例组的共同作用，是让读者看到同一大类动词在组合能力上的差别。像“睡觉、革命、吃亏”这样的词，通过插入、重叠或变换显示内部结构对句法操作的反应，说明次范畴不只是词义分类，而是与句法组合和变换能力相连。

### 6. 让例外在框架内得到解释

论文处理动词的交叉和兼类时，没有把例外简单排除。作者承认不同角度的分类会产生交叉，但同时强调同一层级要有同一标准。若某词在不同框架中表现不同，应当说明它属于哪一个分类步骤中的现象，必要时再设下位类别。

这种处理对论文写作很重要：例外出现时，可以先检查是标准使用混乱、观察单位不一致，还是对象本身具有跨类功能。明确原因后再决定修正标准、增加层级，还是作为兼类处理。

## （四）写作技法

**第一，用“研究平面”控制讨论范围。** 句法、语义、语用并列出场，但本文只从句法平面取证据。范围一旦确立，后续论证不再漂移。

**第二，先原则，后操作。** 三条原则在前，具体功能框架在后。原则不是口号，而是直接决定选取什么形式、在哪里观察、如何分层。

**第三，把定义转成测试。** “语法功能”没有停留在抽象定义，而被转换为能否进入功能框架、能否带某类宾语、能否单独作谓语等检查动作。

**第四，层级图式清楚。** 从有宾、无宾到下位类型，分类的树状关系容易追踪。读者可以沿着每一步判断某词为何被归入某一类。

**第五，分类与说明同时推进。** 作者不仅列类别，还解释为何采用这一标准、为何某类需要继续下分、交叉现象为何存在。分类结果因此有方法背景。

## （五）原文摘录与可模仿动作

| 原文摘录 | 论证功能 | 可模仿动作 |
| --- | --- | --- |
| “从句法平面给词进行分类，根据的是词的语法功能。” | 把分类依据固定在句法功能，避免在不同平面之间跳转 | 在方法部分明确证据来源，并说明其他平面只作补充还是暂不讨论 |
| “从形式出发去探求功能” | 规定发现程序：先观察外现形式，再概括功能意义 | 把抽象概念转换成可观察的分布、组合和变换测试 |
| “从词组（短语）里确认功能” | 把观察单位限定在静态词组，减少句子语境带来的干扰 | 说明每项判断在什么最小单位中完成，保证不同词项可比 |
| “多角度多层级分类” | 承认动词复杂性的同时，避免多标准同时使用 | 每一层只设一项主导标准，层与层之间的标准可以不同 |
| “动词 + 实词”等功能框架 | 把理论原则落实为可操作的准入测试 | 设计能重复使用的格式，让能进入和不能进入的项目形成对照 |
| 借、租、接、收、受等对比 | 通过组合差异显示动词内部次类 | 用成组典型词项建立边界，再补充边缘词项检查 |

## （六）如何升级到当代研究

这篇论文的突出优点是分类原则和功能框架清楚，便于复制到其他词类或其他次范畴研究。它的进一步推进，可以先从框架效度、语料范围和跨平面解释展开。

第一，功能框架需要接受效度检验。某一框架能够区分选定词项，不等于它对整个词库都稳定。后续研究可以用大词表测试框架的覆盖率、误判率和层级稳定性，报告无法归类的词项，而不是只展示框架成功的例子。

第二，静态词组可以发展为多语境的用法调查。静态形式便于控制变量，却可能忽略真实话语中的省略、移位、指称和信息结构。把短语测试与自然语料中的实际分布结合，可以判断某项功能是语法能力、语用偏好还是体裁特征。

第三，句法分类可以与语义特征建立更精细的映射。动词能否带某类宾语，常与事件结构、参与者角色、体特征和名词语义相关。后续研究可把这些因素形式化，检验句法框架是否由更一般的语义限制驱动。

第四，兼类与交叉现象需要概率化处理。传统分类常给出“属于 / 不属于”的判断，但真实词库可能呈现强弱不同的倾向。基于语料频次和统计模型，可以描述一个动词在多大程度上表现出某类功能，并观察语境如何改变其表现。

第五，跨语言和方言材料可以扩展框架的外部检验。若同一框架能解释普通话、方言和其他语言的动词分类，它的理论价值更高；若只适用于有限语料，则应说明适用条件。

批判性提示的重点是：功能框架越清楚，越要防止把框架当成自然类别。框架是研究工具，工具应当接受覆盖率、反例和可复现性的检验。

# 四、陆俭明《关于汉语词类的划分》

## （一）论文任务与问题切口

论文从汉语词类研究的历史困难进入：

> “汉语词类问题始终是汉语语法研究中一个老大难的问题。问题的症结在于……”[^6]

作者没有把困难归为材料不足，而是归到理论来源和研究方式：有关划类的理论、思想来自印欧语，未必适合汉语；学界讨论多，逐词研究少。随后又以参加大规模词类研究项目的经历为背景，交代本文要汇报个人认识。

这一切口具有双重作用。它把论文放进长期争论之中，说明研究不是凭空提出；同时又把宏大的历史问题转成一个可操作的理论问题：划分词类的依据、标准和步骤究竟是什么。

## （二）论证链结构

**结构流程**：旧说和长期争论 -> 诊断症结 -> 排除词义和词形等不适当依据 -> 确立语法功能 -> 澄清性质、特点和标准等元概念 -> 说明多层划分和步骤 -> 处理兼类、例外与连续统 -> 交代局限

论文不仅给出结论，还花大量篇幅澄清讨论中经常混合的概念。它把“依据是什么”“某类词具有什么性质”“用什么标准划分”“在什么层级划分”“如何处理例外”分别拆开。论证的深度主要体现在这些区分上。

## （三）客观拆解

### 1. 从历史争论中提炼真实症结

论文先概括学界长期争论，但并不只做文献综述。作者把争论背后的共同困难压缩为两点：理论移植造成认识偏差，缺少面对具体词项的扎实研究。这样的综述有方向性，读者能看出旧说为什么没有解决根本问题。

可模仿的动作是：综述不是按时间罗列观点，而是寻找争论反复出现的共同前提。若多个旧说共享一个未经检验的前提，新的论证就可以从这个前提入手。

### 2. 把依据收敛到语法功能

论文明确：

> “划分词类的依据只能是词的语法功能，这是划分词类最本质的依据。”[^7]

作者在确立这一核心后，继续讨论词类划分不能依赖单纯词义，也不能依赖汉语中不稳定的词形变化。语法功能因此成为贯穿全文的判断依据，也是后续多层分类的共同基础。

这种写法把原则放在论文枢纽位置。后续概念澄清、分类层级和兼类处理，都围绕“语法功能”展开。核心标准一旦分散，分类程序就会失去统一性；核心标准一旦过于抽象，又会无法操作，所以作者把它连接到词和词的组合能力及句法功能。

### 3. 区分性质、特点和划类标准

论文指出，某类词的语法性质是该类词所具有的语法功能总和，既包括特有功能，也包括与其他词类共有的功能；语法特点则是该类词具有而其他类词不具有的功能。划类标准不一定总从语法特点中选取，因为词类是分层划分的，某层也可以从一般语法性质中选取标准。

这一区分能够防止常见错误：把几类词共有的功能当成某一类词的个性，或者把“某类词的功能清单”直接当成“划类标准”。论文由此把描写与操作分开，读者可以知道某条功能用于认识词类，还是用于实际划类。

### 4. 把词类划分当作有步骤的层级工程

论文强调词类是多层划分得到的，每层可以采用单一标准或多重标准。使用多重标准时，各项标准之间必须有共性，不能在互不相关的维度上随意拼接。划分步骤也很重要，因为层级顺序会直接影响分类结果。

这套思路把词类划分从“选择一种标准”推进为“设计一套程序”。即便两个人使用相同的语法功能，只要层级顺序不同，得到的类别也可能不同。论文因此要求作者交代标准的选取、层级的关系和步骤的顺序。

### 5. 用同一性原则处理兼类

兼类判断要求遵守“同音同义”的同一性原则。也就是说，一个词在不同功能中的意义应当相同，读音也应当相同，不能把同音同形但意义不同的词简单合并为兼类。这个条件使兼类判断不只看句法位置，还要控制词项身份。

这种处理方式可迁移到许多分类问题：当同一形式在不同环境中表现不同，先确认这些表现是否属于同一对象。如果对象身份已经变化，所谓的“兼类”可能只是同形异义。

### 6. 承认词类的连续统和例外

论文指出，词汇系统复杂而非离散：

> “词汇是一个系统，但它不是一个离散的系统，它是一个非常复杂的连续统。因此，不管用怎样合理的划类标准来对它进行分类，都不可能分得一干二净，总会遗留下一些让人感到棘手的词，总会遇到例外现象和难处理的词。对此我们只能老老实实分别情况作特别说明。”[^8]

这段文字体现了论文的自我限定。作者没有承诺分类能够消除全部边缘现象，而是把例外处理纳入研究程序。一个分类方案的可信度，不只看典型词项归得多整齐，也看它怎样报告和解释边缘词项。

## （四）写作技法

**第一，综述直接服务于问题诊断。** 历史争论不是背景装饰，而是说明本文为何要从依据、标准和步骤重新入手。

**第二，核心命题反复回扣。** “语法功能”作为最本质依据贯穿概念澄清和分类程序，避免论文在中途转向其他标准。

**第三，元概念辨析充分。** 语法性质、语法特点、划类标准、依据、标准、步骤等概念被逐项区分。概念越纠缠，作者越先做定义和关系说明。

**第四，理论反思与大规模调查相连。** 论文批评只停留在理论争论，同时交代逐词研究经验，使反思具有材料背景。

**第五，结论带有限度。** 作者承认连续统、例外和难处理词项，避免把分类方案写成覆盖一切对象的封闭系统。

## （五）原文摘录与可模仿动作

| 原文摘录 | 论证功能 | 可模仿动作 |
| --- | --- | --- |
| “汉语词类问题始终是汉语语法研究中一个老大难的问题。” | 把论文放进长期争论，建立问题重要性 | 在引言中说明争议持续在哪里，而不是只说题目重要 |
| “划分词类的依据只能是词的语法功能” | 给出全文最核心的判断标准 | 用一句可检验的命题固定全文依据，后文不随意更换 |
| 语法性质、语法特点和划类标准的区分 | 防止把功能清单直接等同于分类标准 | 把研究对象“有什么特征”与“按什么标准分类”分开表述 |
| 词类分层划分，划分步骤很重要 | 将分类从选标准推进为设计程序 | 明确每一层的标准、顺序和适用对象，并说明顺序变化的影响 |
| 兼类须遵守“同音同义”的同一性原则 | 控制兼类判断中的词项身份 | 在跨类判断前先检查读音、意义和对象身份是否相同 |
| “词汇……是一个非常复杂的连续统”及例外说明 | 承认分类限度，要求报告边界问题 | 在结论中列出难处理项、处理方式和仍未解决的问题 |

## （六）如何升级到当代研究

陆俭明对依据、标准和步骤的澄清，为词类研究建立了方法论框架。进一步研究可以从标准效度、连续统建模、词库规模和跨语言验证几个方向推进。

第一，语法功能标准可以量化。传统划类常用能进入、不能进入的二元判断，但真实语料中不同功能出现的频率差异很大。后续研究可以把句法环境作为变量，通过聚类、分类树或混合模型观察词类边界，报告边界词和分类不确定性。

第二，连续统可以转为可视化模型。承认词类不是离散系统之后，还需要说明连续统的维度是什么、哪些功能推动词从一类向另一类移动。多维尺度分析、网络分析或原型模型都可以帮助呈现词与词之间的远近关系。

第三，多层划分可以加入程序透明度检验。研究者可以比较不同层级顺序、不同标准组合对分类结果的稳定影响，甚至用留出法检验模型对新词的预测能力。这样，划分步骤不只是一套叙述顺序，也能成为可评估的算法。

第四，兼类判断可以结合词义消歧和构式环境。同音同义原则提供了必要条件，但许多词的词义会随语境发生细微变化。使用标注语料和词义消歧工具，可以更细地说明功能变化是否伴随意义变化。

第五，词类理论可以接受跨语言和跨方言检验。若某一功能标准在现代汉语普通话中有效，还应检查它在方言、历史文献和其他语言中的表现，以判断该标准反映的是汉语共性、语言共性还是特定语体特征。

批判性提示的重点是：承认连续统不等于放弃分类。好的当代研究应当同时报告类别、边界、概率和不确定性，让分类成为可检验的工具，而不是只靠典型例子维持清晰外观。

# 五、邢福义《说“NP了”句式》

## （一）论文任务与问题切口

论文从具体语言事实进入：名词或名词短语带上“了”可以成为分句，并与其他分句组成复句。作者先列出两个基本格式：

> “NP了，S”“S，NP了”[^9]

接着用“大姑娘了，要注意整洁”“大姑娘了，一件像样的衣服也没有”“要注意整洁，大姑娘了”等例子展示构成和用法。这个起点非常具体，读者可以先看见语言现象，再进入句法和语义条件。

论文标题也控制得精确：研究对象是“NP了”句式，而不是泛论“了”或名词谓语句。标题、开头格式和后续分析彼此对应，论文边界清楚。

## （二）论证链结构

**结构流程**：语言事实 -> 基本格式 -> 删除和变换检验 -> 最小对比确认“了”的作用 -> 按分句关系分类 -> 提炼NP的推移性等核心语义条件 -> 说明自足性、否定和句法限制 -> 用反例划定边界

论文的推进方式很像逐层收紧筛选条件。先说明什么形式可以成句，再问“了”能否删除，随后区分前置和后置格式的关系，最后集中解释为什么有的名词短语能进入、有的不能。

## （三）客观拆解

### 1. 从可观察格式建立研究单位

作者一开始不讨论“了”的全部功能，只列出“NP了”在复句中的两个位置。格式把复杂现象切成可比较的单位，后续删除、移位和变换都围绕这两个位置进行。

可模仿的动作是：句式研究先固定最小格式。格式越清楚，例子之间的差异越容易定位，读者也能判断某个反例只是材料变化，还是规则需要修正。

### 2. 用删除法确认关键成分

论文比较“大姑娘了”与“大姑娘”。没有“了”时，NP和后续分句或者不能构成原来的复句关系，或者“大姑娘”只能分析为主语、呼语等。作者由此说明，“NP了”能够成为分句的关键是助词“了”。

删除法在这里不是简单做减法，而是建立最小对照：其他成分保持稳定，只移除一个成分，观察合法性和句法身份是否改变。若改变，该成分就成为论证中心。

### 3. 用移位观察格式差异

论文区分“NP了，S”与“S，NP了”。同一个“NP了”在前分句和后分句时，与后续或前文分句的关系不同。作者没有把两个格式合并成一条规则，而是分别讨论，避免掩盖位置带来的功能变化。

这种写法提醒论文作者：一个形式出现在不同位置时，要先判断是否仍属于同一研究对象。若句法关系已经改变，就应分节处理，而不是为了目录整齐强行合并。

### 4. 按分句关系继续分类

论文讨论因果关系、转折关系、倒置因果、倒置转折、归结关系等。“NP了，S”可以分为因果式和转折式；“S，NP了”同样需要按照前后分句的关系继续分析。分类的依据是分句之间的逻辑和语用联系，而不是例子的外部题材。

这种分类使句法格式与篇章关系相接。一个句式是否成立，不只取决于内部形式，还取决于它能否承担特定的话语推进或评价功能。

### 5. 从大量用例中提炼“推移性”

论文提出，能够进入“NP了”的NP具有推移性。它所表示的概念由相对概念推移而来，原来并非如此。[^10] “大姑娘了”意味着从较小年龄向“大姑娘”这一阶段的推移；“百把斤的猪了”意味着猪从不到百把斤向百把斤推移。

“推移性”是全文最有解释力的语义条件。它能够统一人物、时点和时段等多类NP：年龄阶段、年代、季节、时间点、时段长度都可以在时间或状态维度上发生推移。

### 6. 用反例检验语义条件

论文用“猪了”和“小孩子了”等反例说明，缺少推移性的名词不能随意进入该句式；而“百把斤的猪了”“大孩子了”可以成立，因为NP已经包含从彼到此的变化信息。反例在此直接检验核心条件，而不是孤立补充。

反例还帮助说明修饰成分的作用。“猪”本身表示一个类别，不能显示状态阶段；“百把斤的猪”通过数量和属性限定了阶段，因此具备推移性。语义条件由此从句法限制中浮现。

### 7. 补充自足性和否定限制

论文指出，“NP了”具有自足性，不需补上主语，也不能直接补上主语；同时，“NP了”不能直接采用否定形式。[^11] 这些限制与句式功能相互印证：它不是普通的主谓陈述，而是对变化结果的确认或评说。

作者在给出核心条件后继续检查句法限制，使语义概括获得多重证据。若“推移性”是进入条件，自足性和否定限制则说明进入以后该格式承担的句法、语用功能。

## （四）写作技法

**第一，开头用事实带出格式。** 论文不从抽象定义开始，而是让读者先看到“大姑娘了”怎样构成分句。具体例子降低了进入门槛。

**第二，删除和移位交替使用。** 删除“了”确认关键成分，移位区分前置和后置格式。两种操作共同揭示句法关系，而不是只靠静态分类。

**第三，最小对比贯穿全文。** 能说与不能说、加“了”与不加“了”、前置与后置、典型与反例，几乎每个论点都有成对材料支持。

**第四，语义概括可覆盖多类NP。** “推移性”不是只解释年龄称谓，而能统一人物、时点、时段等不同类型，因此具有概括力。

**第五，例证来源接触真实语篇。** 论文使用大量文学、期刊和口语例子，观察句式在篇章中的位置和功能，使句法描写不停留在人工造句。

**第六，限制条件紧接核心规则。** 自足性、否定限制与推移性依次出现，构成规则的正面条件、反面限制和句法后果。

| 原文摘录 | 论证功能 | 可模仿动作 |
| --- | --- | --- |

| 因果式、转折式等关系分类 | 把句法格式连接到分句关系和话语功能 | 先按结构分格式，再按表达关系分层，不混用两组标准 |
| “能进入‘NP了’句式的NP具有推移性” | 提炼能够覆盖多类NP的核心语义条件 | 从多组材料中找共同变化维度，让一个条件解释多个类别 |

| “‘NP了’不能直接采用否定形式” | 用反面限制界定句式的语法性质 | 在正面准入条件之外，补充不可出现的结构和变换 |
| “百把斤的猪了”与“猪了” | 用最小反例证明推移性是进入条件 | 选择只差一个关键属性的例子，展示规则为何排除其中一项 |

## （六）如何升级到当代研究

邢福义的研究以真实例证、最小对比和语义条件见长。把这一范式推进到当代研究，可以加强语料统计、语篇功能、历时变化和构式解释。

第一，语料可以从作家例句扩展为平衡语料库。人工例证长于展示可能性，平衡语料可以报告不同格式在新闻、小说、口语和网络语言中的频次。研究者还可以提取搭配词、年龄阶段词和时间词，检验推移性的分布特征。

第二，语篇功能可以系统标注。“NP了”前置或后置时，究竟承担提醒、责备、评价、解释还是话题推进，可以由多名标注者进行功能标注，并计算一致性。这样能把直觉判断转为可复核的语篇证据。

第三，推移性可以形式化。研究者可以把它拆为状态阶段、比较基准、时间方向和预设变化等变量，检查哪些变量是必要条件，哪些只提高可接受度。若某些NP呈现局部例外，可以报告为条件概率，而不是简单归入反例。

第四，句法和韵律可以结合。该句式常用于口语，句末“了”的韵律、停顿和语调可能影响其功能。语音实验能够检验文字材料里看不见的韵律条件。

第五，构式语法可以解释形式和功能如何绑定。把“NP了”视为一个具有形式和语义极的构式，可以讨论NP槽位的选择限制、构式义与词汇义的互动，以及否定义为何不易进入。

批判性提示的重点是：经典句式的规则往往高度精炼，但精炼也可能掩盖语境差异。当代研究应在不破坏最小对比的前提下增加数据维度，让规则的条件和概率得到更完整的呈现。

## （三）四篇论文共同提供的写作公式

第一，用一个具体问题替代宽泛题目。问题应包含对象、对立或争议、观察平面和待回答的差别。

第二，用最小格式或核心标准建立论证主轴。主轴必须在全文反复出现，不能被后续材料和术语带离。

第三，用成组证据推进，而不是用单个例子证明结论。每组证据只改变关键变量，并说明这个变量影响什么判断。

第四，先分类，再处理交叉。每一层只使用一项主导标准；若同一对象跨层，就交代它在不同层级中的身份。

第五，先写功能或格式事实，再写语义概括。概括应当受证据约束，不能反过来替代证据。

第六，以反例检查边界。反例出现后，选择细化条件、增加层级或明确例外，而不是删除不利材料。

第七，结论要交代限度。可以说明尚未讨论的平面、语料范围、难以处理的词项或仍未解决的问题，使论文的结论与证据范围相称。

## （四）可效仿的段落推进方式

四篇论文都常采用“提出判断—给出成组例子—解释差别—回扣框架”的段落结构。段落开头先指向一个待判断的问题，中段用最短的例组证明差别，结尾把差别归回上位标准或分类框架。这样的段落不靠连接词堆叠，而靠证据关系自然推进。

另一种常见结构是“旧说—问题—本文处理”。它适合理论争论较多的论文。先概括旧说共同困难，再说明本文从哪个概念或程序入手，最后交代本文不处理什么。陆俭明的文章在这条路径上最为集中，胡裕树、范晓的文章也在开头使用了类似功能。

句式研究则常用“格式—变换—条件—限制”。邢福义先列基本格式，再通过删除、移位和关系分类提炼“推移性”，最后补充自足性和否定限制。写作时应保持这四类内容的顺序，避免在没有确认格式之前就展开语义解释。

“要锤炼对典型论著和代表性作品写作技法、研究范式的感受度。学习名家论文，不仅要学习观点、结论，还要学习如何提出问题、分析问题、解决问题，学习怎样剪裁材料、安排段落、使用文献，怎样写摘要、关键词、引言、结语、余论和参考文献。”

“吕叔湘、朱德熙、胡裕树、张斌、陆俭明、邢福义、范晓、沈家煊等学者各有风格和研究范式。阅读时应比较他们怎样选择问题、界定对象、组织证据和形成结论，从中积累可以迁移到自身论文写作中的结构动作。”
